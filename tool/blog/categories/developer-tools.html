Guides for the tools developers use daily

Formatting JSON, testing a regular expression, generating a hash or decoding a token are small jobs that interrupt real work. The guides here explain what each developer tool does under the hood, so you can trust the output and spot when the input, rather than the tool, is the problem.

What to expect

  • Plain explanations of formats and algorithms, such as why a hash is not encryption and why Base64 is not security.
  • Worked examples with realistic input, including the malformed input that usually causes errors.
  • Notes on browser-side processing, so you know what stays on your machine.

Good habits when using online developer tools

Never paste production secrets, API keys or private tokens into any online tool unless you have confirmed it processes data locally. Validate output against your own tests before shipping it. When two tools disagree, check which specification each follows; most disagreements come from differences in strictness, not from bugs.
