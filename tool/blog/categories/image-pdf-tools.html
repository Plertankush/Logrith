Practical help for images and PDFs

Most image and PDF problems are about limits: an upload form that rejects a file over 200 KB, a scan that arrives sideways, or a document with a page you should not share. These guides walk through the real situations and explain which setting solves each one.

What you will learn

  • Images: when to resize, crop or compress, how JPG, PNG and WebP differ, and how to hit a target file size without visible damage.
  • PDFs: merging, splitting, rotating, compressing, watermarking and password-protecting, including what each operation changes in the file.
  • Conversion: choosing a sensible DPI when turning PDF pages into images, and turning photos into a single PDF.

Your files stay on your device

Logrith's image and PDF tools process files inside your browser, so documents are not uploaded to a server. For very large files, close other tabs first; browser memory is the practical limit. Always keep the original and check the result before sending it.
