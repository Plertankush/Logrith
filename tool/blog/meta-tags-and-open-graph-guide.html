Meta Tags and Open Graph: What Each Tag Does and How to Get Them Right

A page’s head section decides how it appears in search results and in a shared link. Many sites carry dozens of tags that do nothing and miss the few that matter. This guide separates the two, with the lengths and sizes to aim for.

The Tags That Matter

The title is the strongest of these, because it is both a signal about the page and the first thing a searcher reads. The description is not a ranking signal, but it is your short pitch under the title, so it is worth writing carefully.

Title and Description Length

Search engines truncate by pixel width, not by character count, so the figures below are practical targets.

ElementTargetTip
TitleAbout 50 to 60 charactersPut the main phrase first and the brand last
DescriptionAbout 70 to 160 charactersSay what the page offers and why to click
og:titleUp to about 70 charactersCan match the page title
og:descriptionUp to about 110 charactersShorter text often reads better on cards
Share image1200 x 630 pixelsFull https address, small file size

Search engines may rewrite your title or snippet if they think another part of the page answers the query better. A unique, accurate title and description make that less likely.

Open Graph and Twitter Card Tags

Open Graph is a set of tags, introduced by Facebook, that most social networks and chat apps read to build a link preview. The core set is small:

  • og:title and og:description give the card its text.
  • og:image is the picture. It must be a full address, not a relative path.
  • og:url is the page address, normally the same as the canonical link.
  • og:type is website for most pages and article for posts.
  • og:site_name shows your brand name.

For X, add twitter:card with the value summary_large_image for a wide picture or summary for a small square one. Include an alt text for the image so the card is accessible.

Robots and Canonical Tags

ValueEffect
index, followThe default. The page may be indexed and its links followed.
noindexAsks search engines to keep the page out of results.
nofollowAsks search engines not to follow the links on the page.
noindex, nofollowBoth of the above.

Only use noindex on pages you really want hidden, such as thank-you pages or internal search results. The canonical link is a hint, not a command, but it helps when the same content is reachable through several addresses, for example with tracking parameters.

Common Mistakes

  • Using the same title on every page. Each page needs its own, or search engines cannot tell them apart.
  • A relative image path in og:image. Social networks need the full https address.
  • Leaving noindex on after launch. Staging settings often survive into production and hide the whole site.
  • Stuffing keywords into the description. It reads badly and does not help ranking.
  • A canonical link that points to another page by accident. That tells search engines to ignore this one.
  • Forgetting to refresh cached previews after changing the image or title.

Frequently Asked Questions

Do meta descriptions affect Google rankings?

Google has said it does not use the meta description as a ranking signal. It can still be shown as the snippet under your title, so a clear description can improve how many people click your result.

Does the meta keywords tag still matter?

No. Google does not use the meta keywords tag, and most other major search engines ignore it too. You can leave it out of new pages.

How long should a title tag and meta description be?

Aim for about 60 characters for the title and up to about 160 for the description. These are guides, not hard limits, because search engines cut text by pixel width and may rewrite what they show.

What size should an Open Graph image be?

1200 x 630 pixels (a 1.91:1 ratio) works well on most platforms. Use a full https address on your own domain, keep important content away from the edges, and keep the file reasonably small.

Why does my shared link show an old preview?

Social networks cache previews. After you change tags or the image, use the platform's sharing debugger or post preview tool to refresh the cached version.

Do I need Twitter Card tags if I have Open Graph tags?

Not always. Several platforms fall back to Open Graph tags, but twitter:card tells X which layout to use, so adding it gives you control over the large-image or summary layout.

Conclusion

Focus on a unique title, an honest description, a canonical link and a correct share image on every page, and skip the tags that no longer matter. Then look at the previews before you publish.
