About the PDF Split Tool

The Logrith PDF Split tool lets you extract specific pages or split an entire PDF into individual page files, free and directly in your browser. Whether you need to pull a single chapter out of a long report, separate an invoice from a multi-page scanned batch, or break a document into one file per page, this tool handles it without needing Adobe Acrobat or any other desktop software installed.

PDF splitting is one of the most common document tasks people run into — a scanned batch of receipts that needs separating into individual files, a textbook PDF where you only need one chapter, or a signed contract where you want to pull out just the signature page to send separately. This tool covers both the "extract specific pages" use case and the "split into one file per page" use case from the same interface.

Two Ways to Split a PDF

  • Extract a page range. Enter specific pages or ranges — like "1-5, 8, 10-12" — to pull out exactly the pages you need into a single new PDF file.
  • Split into individual pages. Choose the "Split All Pages" option to break the entire document apart, with every page becoming its own separate, downloadable PDF file.

How the Page Range Syntax Works

The page range field accepts a flexible, comma-separated format that mixes individual page numbers and ranges. A dash between two numbers (like "10-12") means every page from the first number to the second, inclusive. A single number on its own (like "8") pulls just that one page. You can combine as many of these as you need, separated by commas, and the tool reads them left to right, extracting pages in the order you listed them.

Common Use Cases for Splitting PDFs

  • Separating invoices or receipts that were scanned together into one long PDF, so each can be filed or sent individually.
  • Extracting a chapter or section from a long ebook, report, or textbook without sending the entire document.
  • Pulling out a signature page from a signed contract or agreement to send as a standalone confirmation.
  • Isolating specific exam or assignment pages from a larger scanned bundle for grading or submission.
  • Reducing file size by extracting only the pages you actually need, rather than sharing an entire bulky document.

Does Splitting Affect PDF Quality?

No. This tool uses PDF-Lib, a library that works with the PDF's internal page structure directly rather than converting pages to images and back. That means text stays selectable, embedded fonts remain intact, and any images inside the original pages keep their original resolution. Splitting a PDF this way is fundamentally different from, say, converting pages to JPG and back to PDF, which would introduce quality loss — nothing here gets re-rendered or re-compressed.

Privacy and Browser-Based Processing

Because the entire split operation runs client-side in your browser using JavaScript, your original PDF file is never uploaded to any server. There's no file storage, no account requirement, and no record kept of what you've processed. This makes the tool a safe choice for splitting PDFs that contain personal, financial, or otherwise sensitive information, since the content never travels over the internet in the first place.

Splitting vs. Merging: Knowing Which You Need

It's easy to mix up splitting and merging when you're dealing with multiple PDF files. Splitting takes one PDF and breaks it apart into smaller pieces — either a specific page range or every page individually. Merging does the opposite: it takes several separate PDF files and combines them into one. If you've received a bundle of documents scanned together as one file and need to separate them, you want to split. If you have several separate files that you want combined into a single document to send or print together, you want to merge instead — Logrith's PDF Merge tool handles that side of the workflow.
