Frequently Asked Questions

What is a diceware passphrase?

A passphrase created by randomly selecting words from a large word list, originally using physical dice. The resulting phrase is easier to remember than random characters while resisting guessing.

Is a passphrase more secure than a random password?

A sufficiently long passphrase (4+ random words) can match or exceed the entropy of a shorter random-character password, while being much easier to remember and type.

How is this different from the Password Generator tool?

The Password Generator creates random character strings (like "K9#mP2$vL"). This tool creates memorable multi-word phrases (like "Tiger-River-Cloud-42") that are easier for humans to recall.

Is my generated passphrase sent to a server?

No, generation happens entirely in your browser using the Web Crypto API. Nothing is transmitted anywhere.

Where does the word "diceware" come from?

Diceware is named after its original method: rolling physical dice to randomly select words from a numbered list, a technique developed specifically to generate passphrases with verifiable, unbiased randomness before computers made digital random generation convenient.

Should I add a number or symbol to my passphrase?

Yes, where the account allows it. A random number appended to the end meaningfully increases the total possible combinations with minimal added difficulty to remember or type.

Unlike a random string of characters, a multi-word passphrase is genuinely easier for humans to remember and type accurately, while still providing strong resistance against guessing attacks when enough words are used.

Why Passphrases Work Well

The security of a passphrase comes from the total number of possible combinations, not from using obscure symbols. If you randomly select from a word list of, say, 150 words, each additional word multiplies the total number of possible passphrases by 150. Four random words from such a list already produce well over 500 million possible combinations — far more resistant to automated guessing than most people expect, while remaining genuinely memorable, unlike a string like "Xk9#mQ2$vLp."

Passphrase vs. Traditional Password

Traditional advice pushed for short, complex passwords mixing uppercase, lowercase, numbers, and symbols — but these are often hard to remember and prone to being written down or reused. A longer passphrase built from multiple random words achieves comparable or better resistance to brute-force guessing, while being significantly easier for a person to actually remember without writing it down, which reduces a different, very common security risk.

Why Word Count Matters More Than Word Complexity

A common instinct is to pick obscure or unusual words to feel more secure, but this misunderstands where a passphrase's strength actually comes from. Security comes from the total search space an attacker would need to try — which depends on how many words are randomly selected and how large the word list is, not on whether any individual word feels exotic. Using unusual words instead of common ones doesn't meaningfully increase security if drawn from the same size word list; what matters is adding another random word to the phrase, since each additional word multiplies the total combinations by the full size of the word list.

Tips for Using This Tool

  • Use at least 4 words for meaningful security — more words meaningfully increase the total combinations.
  • Adding a number further increases the search space an attacker would need to try.
  • Choose a consistent separator that's easy for you to type reliably.
  • Still use a password manager where possible — passphrases are for cases where you need to actually remember and type a credential yourself.

How This Tool's Word List Was Chosen

The word list used for generation draws from common, easy-to-spell, everyday English words, deliberately avoiding obscure terms, homophones, or words with ambiguous spelling that could make a generated passphrase harder to type back correctly from memory. This matters because a passphrase that's technically random but full of hard-to-spell words defeats part of the purpose — the whole point of a passphrase over a random character string is that a human can reliably reproduce it, which requires every word in the pool to be unambiguous and simple to type correctly on the first attempt.

When a Passphrase Is the Better Choice

A passphrase makes the most sense specifically for credentials you need to type manually and remember without a password manager — a device unlock passcode, a master password for a password manager itself, or a shared household WiFi password that multiple people need to type on different devices. For every other account, where a password manager can generate and store a long random password you never need to type or memorize, a traditional random-character password remains a perfectly strong choice, and the two approaches aren't in competition so much as suited to different situations.

Why Predictable Word Patterns Weaken a Passphrase

The security math behind passphrases assumes the words are genuinely randomly selected from the full word list — not chosen by a person trying to construct something memorable, which tends to introduce predictable patterns. A passphrase like "correct-horse-battery-staple," while a well-known example of the concept, would actually be a weak real-world choice specifically because it's now widely recognized, meaning an attacker's guessing list would likely include it directly. This is exactly why this tool uses true random selection rather than letting you hand-pick memorable words — genuine randomness, not perceived cleverness, is what provides real security against automated guessing.

Memorization Tips for a Newly Generated Passphrase

A freshly generated random passphrase won't feel memorable immediately, but a few techniques help it stick faster than simply staring at it repeatedly. Try constructing a brief, even absurd, mental image or short story connecting the words in order — the more vivid or unusual the imagined scene, the more memorable it tends to be, since human memory generally retains distinctive imagery better than arbitrary text. Typing the passphrase out manually several times in the minutes after generating it, rather than only reading it silently, also reinforces muscle memory in a way that pure visual review doesn't achieve nearly as effectively, especially for a passphrase you'll need to type from memory regularly.
