Frequently Asked Questions

How secure are the generated passwords?

Very secure. The generator uses the Web Crypto API (crypto.getRandomValues) which is cryptographically secure randomness, the same standard used by security software and operating systems.

Are my passwords stored anywhere?

No. Passwords are generated purely in your browser using JavaScript. Nothing is sent to any server. The history shown is only in your browser's memory and disappears when you close the tab.

What makes a strong password?

A strong password is: at least 12 characters long (16+ is better), uses a mix of uppercase, lowercase, numbers and symbols, is not based on dictionary words, and is unique to each account.

What is the "Exclude Ambiguous" option?

It removes characters that look similar when typed: 0 (zero) vs O (letter), 1 (one) vs l (lowercase L) vs I (uppercase i). Useful for passwords that need to be read aloud or typed manually.

How do I use the bulk generator?

Enter the number of passwords you need (max 100), choose a separator, and click Generate Bulk. All passwords use the same settings from the main generator above.

Can I generate a password without symbols?

Yes, uncheck the Symbols option if a specific account or form doesn't accept special characters. Keep in mind this slightly reduces the character pool, so consider increasing the length to compensate.

What's the ideal password length?

Most current security guidance recommends at least 16 characters for important accounts, since length contributes more to security than character variety alone.

Should I save generated passwords somewhere?

Yes, since these passwords are randomly generated and not based on anything memorable, saving them in a reputable password manager is strongly recommended rather than trying to remember them.

Why You Need Strong Passwords

Data breaches expose millions of passwords every year. Using weak or reused passwords is one of the biggest security risks for individuals and businesses. A strong, unique password for each account — combined with a password manager — is the most effective protection.

Logrith's password generator uses cryptographically secure randomness (the Web Crypto API) to ensure no pattern can be predicted. Unlike online generators that might log your requests, this tool generates everything locally in your browser — your passwords never leave your device.

Why Cryptographic Randomness Matters

Not all "random" is equally secure. Many simpler random number generators, including JavaScript's standard Math.random(), are designed for general-purpose randomness like games or shuffling — not for security-critical applications. Given enough observed output, some of these generators can theoretically be predicted by an attacker who understands the underlying algorithm. The Web Crypto API's crypto.getRandomValues(), which this tool uses, is built specifically for security purposes, drawing from the operating system's cryptographically secure random source — the same category of randomness used for generating encryption keys. This is a meaningfully stronger foundation for something as sensitive as a password.

What Actually Makes a Password Hard to Crack

Password strength comes down to how many possible combinations an attacker would need to try before guessing correctly, a value that grows exponentially with length and with the size of the character set used. A 20-character password drawing from uppercase, lowercase, digits, and symbols has an astronomically larger number of possible combinations than an 8-character password using only lowercase letters — length matters more than people often assume, which is why this tool defaults to 16 characters and allows up to 128.

Understanding the Strength Meter

The strength indicator on this page scores a password based on several factors together: total length, and whether uppercase letters, lowercase letters, numbers, and symbols are each present. Longer passwords that combine all four character types score highest, since both the length and the variety of possible characters at each position increase the total number of combinations an attacker would need to try. A password scoring "Weak" or "Fair" is still randomly generated and not guessable through dictionary-based attacks, but a few additional characters or an additional character type pushes it meaningfully further out of reach of brute-force attempts.

The "Exclude Ambiguous" and "Similar Characters" Options

Some character combinations are visually confusing, especially in certain fonts: the digit zero (0) versus the uppercase letter O, or the digit one (1) versus lowercase L (l) versus uppercase I. If a password needs to be typed manually from a printed copy, read aloud over the phone, or entered on a device with a small or unclear keyboard, removing these ambiguous characters reduces the chance of a transcription error. For passwords that will only ever be copy-pasted from a password manager, this setting matters less, since there's no manual typing involved to introduce errors.

When to Use the Bulk Generator

The bulk generator is useful whenever you need many independent passwords at once rather than one — setting up a batch of new accounts, generating temporary credentials for a team, or creating test data for a development environment. Every password in a bulk batch is generated independently using the same cryptographically secure method as the single generator, so there's no reduction in randomness or security when generating larger batches.

Privacy: Why Local Generation Matters for Passwords

A password generator that sends your input or output to a remote server — even briefly, even without storing it — introduces a point of exposure that simply doesn't need to exist for a task like this. This tool generates every password entirely within your browser; nothing about the characters you select, the length you choose, or the passwords produced is ever transmitted anywhere.
