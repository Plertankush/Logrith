    Frequently Asked Questions

    What are meta tags?

    Meta tags are small pieces of HTML in the head of a page that describe it to browsers, search engines and social networks. The title and description shape how the page appears in search results, the canonical link names the preferred address, and Open Graph and Twitter tags control the card shown when the link is shared.

    How long should a title tag and meta description be?

    Search engines cut text by pixel width, not by characters, but about 60 characters for the title and about 160 for the description is a safe target. Longer text is usually truncated with an ellipsis. Descriptions under about 70 characters are often too thin to persuade anyone to click.

    Does the meta description affect rankings?

    Not directly. Google has said it does not use the meta description as a ranking signal. It still matters because search engines often show it as the snippet, and a clear snippet earns more clicks. Google may also replace it with text from the page if that matches the search better.

    What size should the Open Graph image be?

    Use 1200 x 630 pixels, a ratio of about 1.91 to 1, saved as PNG or JPEG and kept under a few megabytes. Facebook, LinkedIn, Slack, WhatsApp and X all handle this size. Keep important content away from the edges because some apps crop the image.

    Do I need both Open Graph and Twitter Card tags?

    X (Twitter) falls back to Open Graph tags when it finds no Twitter-specific ones, so Open Graph alone works in most cases. Add twitter:card to choose the large image layout, and twitter:site if you want your account credited. The generator writes both sets so every network has what it needs.

    What does the canonical tag do?

    The canonical link tells search engines which address is the main version of a page when the same content is reachable at several URLs, such as with tracking parameters or with and without www. Always use the full https address of the version you want indexed.

    Why does my shared link still show an old image or title?

    Social networks cache link previews. After you change the tags, ask the network to fetch the page again with its sharing debugger, for example the Facebook Sharing Debugger or the LinkedIn Post Inspector. Some apps refresh after a few days on their own.

    Is my data sent to a server?

    No. The tags and previews are generated in your browser. The only request is the browser loading your share image from the address you typed, so you can see it in the preview.

    About the Meta Tag Generator

    The Logrith Meta Tag Generator writes the HTML that describes your page to search engines and social networks. You enter a title, a description, a URL and an image, and the tool returns a block of tags you can paste into the head of any page, with previews that show how the page will look in Google results and when someone shares the link.

    Meta tags are easy to get slightly wrong and hard to notice when you do. A title that is too long is cut off in the middle of a word, a relative image path produces a blank card on LinkedIn, and a forgotten canonical tag lets the same page compete with itself. The generator checks lengths as you type, escapes quotes and angle brackets correctly, and flags the common mistakes before the page goes live.

    The tags this tool writes

    • Title and description. The title appears as the blue link in search results and in the browser tab. The description is the text under it. Together they decide whether someone clicks.
    • Viewport and charset. The viewport tag makes the page scale correctly on phones. The charset tag tells the browser to read the file as UTF-8 so accents and symbols display properly.
    • Robots. This tells crawlers whether to index the page and follow its links. Leave it on index, follow for pages you want found, and use noindex for thank-you pages, internal search results and drafts.
    • Canonical. This names the preferred address for the page and prevents duplicate-content confusion between URL variants.
    • Open Graph. The og: tags are read by Facebook, LinkedIn, WhatsApp, Slack, Discord and many other apps to build the link card: type, URL, site name, title, description and image.
    • Twitter Card. The twitter: tags choose the card layout on X and credit your account. If they are missing, X falls back to the Open Graph tags.

    Writing a title that works

    Lead with what the page is, not with your brand. People scan results for the answer to their question, so put the main phrase first and the site name last, separated by a vertical bar or dash. Keep it near 60 characters, make it specific, and give every page its own title. Two pages with the same title are hard for both people and search engines to tell apart.

    Writing a description that earns the click

    Treat the description as a short advertisement for the page. Say what the visitor gets, mention one concrete detail, and finish before about 160 characters. Avoid filling it with keywords: Google rewrites descriptions that do not match the search, so a natural sentence that answers the likely question has the best chance of being shown as you wrote it.

    Choosing a share image

    The share image is often the largest thing on a social post, so it is worth getting right. Use 1200 x 630 pixels, put the key message in the middle, and use readable text at a large size. Host the image on your own domain with a full https address. Always add alt text, which also helps screen readers and is used by some platforms when the picture cannot load.

    Common mistakes to avoid

    • Using a relative image path such as /images/card.png. Social networks need the full address including https://.
    • Copying the same title and description to every page on the site.
    • Leaving noindex on a page after launch, which quietly keeps it out of search.
    • Pointing the canonical tag at a different page or at an http address when the site uses https.
    • Forgetting that previews are cached. After a change, refresh the cached card with each network's debugger tool.

    Privacy

    All tags and previews are produced by JavaScript in your browser. Nothing you type is uploaded or stored. The share image is loaded straight from the address you enter, purely so that you can see it in the preview.
