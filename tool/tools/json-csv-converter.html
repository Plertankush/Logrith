Frequently Asked Questions

How do I convert JSON to CSV?

Paste a JSON array of objects, choose a delimiter and click Convert. Each object becomes a row, and the union of all keys becomes the header row. Copy the result or download it as data.csv and open it in Excel or Google Sheets.

What happens to nested objects?

With "Flatten nested objects" on, a value like {"address": {"city": "Pune"}} becomes a column named address.city. Turn the option off to keep nested objects as JSON text inside one cell.

How are arrays handled in CSV?

CSV has no array type, so each array is written into its cell as JSON text, for example ["admin","beta"]. This keeps the data lossless and lets you convert back later.

Does it handle commas and quotes inside values?

Yes. Values containing the delimiter, double quotes or line breaks are wrapped in quotes, and quotes inside are doubled, as the CSV standard (RFC 4180) requires. The CSV parser reads these cases correctly too.

Why do numbers lose leading zeros when I open the CSV in Excel?

Spreadsheets guess types on import and drop leading zeros from values like 00123. Import the file as text for that column, or use the Data > From Text/CSV option instead of double-clicking the file.

What if my JSON objects have different keys?

The header row contains every key found in any object. Rows that lack a key get an empty cell for that column.

Is the data uploaded to a server?

No. Both conversions run in your browser, so confidential data stays on your device.

About the JSON ⇄ CSV Converter

The Logrith JSON ⇄ CSV Converter changes data between the two formats people use most often to move records around. Paste a JSON array and get a CSV file that opens in Excel, Google Sheets or any database import tool. Paste CSV and get a clean JSON array of objects you can use in code or an API. It handles nested data, quoted fields, different delimiters and ragged records, and it runs entirely in your browser.

JSON and CSV solve different problems. JSON is the standard format for APIs and applications because it supports nesting, arrays and typed values. CSV is the standard format for tables because every spreadsheet and analytics tool can read it. Moving between them is a daily job for developers, analysts and marketers, for example when exporting API data for a report, importing a spreadsheet into an app, or preparing a dataset for a script.

How JSON becomes CSV

CSV is flat: rows and columns, nothing else. The converter treats each object in your JSON array as a row. It then collects every key it finds across all the objects to build the header, so records with different fields still line up. Missing values become empty cells. If you paste a single object instead of an array, it is converted as one row, and a list of plain values becomes a one-column table named value.

Nested objects and arrays

Real API responses are rarely flat. A user might have an address object, and an order might have a list of items. With flattening on, nested objects become dot-notation columns such as address.city and address.zip, which spreadsheets handle well. Arrays are written as JSON text in a single cell, such as ["admin","beta"], which preserves the data exactly so you can parse it later. If you prefer to keep nested objects untouched, switch flattening off and each one is stored as JSON text in its cell.

How CSV becomes JSON

The CSV parser follows the common RFC 4180 rules. It understands quoted fields, doubled quotes inside a quoted value, and line breaks inside quotes, so a cell such as "Smith, Liam" stays one value. With "First row is the header" on, the first line supplies the key names. Without it, keys are named column1, column2 and so on. The tool can also detect numbers, true, false and null, so 42 becomes a number rather than the text "42". Turn that off if you need every value to stay a string, for example with ZIP codes or IDs that start with zero.

Choosing a delimiter

Comma is the default, but many European locales use a semicolon because the comma is their decimal separator, and tab-separated files avoid quoting problems when text contains commas. Pick the delimiter that the program receiving the file expects. If a CSV looks like it has only one column, the delimiter is almost always wrong.

Common problems and fixes

  • "Invalid JSON" error. The input has a trailing comma, single quotes or an unquoted key. Fix it with the JSON Repair tool, then convert.
  • Everything lands in one column in Excel. The delimiter does not match your regional settings. Try the semicolon option.
  • Leading zeros disappear. Excel changes 00123 to 123 when opening a CSV. Import the column as text.
  • Garbled accents. Some spreadsheet versions need a UTF-8 byte order mark or an explicit UTF-8 import setting to display non-English characters correctly.
  • Columns are in a surprising order. Columns follow the order in which keys first appear in the data. Reorder them in your spreadsheet if needed.

When not to use CSV

If your data is deeply nested, flattening can produce very wide tables that are hard to use, and you lose the structure. In that case keep the data as JSON, or split the nested parts into separate tables. CSV also has no data types, so dates, numbers and booleans are all text until a program interprets them.

Privacy

Your data is converted with JavaScript running in your browser. It is not uploaded, stored or logged, which makes the tool suitable for customer lists, internal exports and other data you should not paste into a random website.
