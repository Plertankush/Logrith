Preguntas frecuentes

Todo lo que necesitas saber sobre Logrith: cómo funciona, qué es seguro y qué novedades habrá.

General
¿Qué es Logrith?

Logrith es una publicación independiente sobre IA, herramientas para desarrolladores y creadores, con una biblioteca de más de 100 herramientas gratuitas basadas en navegador para edición de imágenes, gestión de PDF, flujos de trabajo de desarrollo, procesamiento de texto y cálculos cotidianos. Todas las herramientas funcionan al 100% en tu navegador: no se requiere subir archivos a un servidor, ni crear una cuenta, ni instalar nada.

¿Es Logrith realmente gratis? ¿Hay costes ocultos?

Completamente gratis, sin excepciones. Sin planes premium, sin créditos de uso, sin marcas de agua en las descargas, sin necesidad de cuenta. La plataforma se financia mediante publicidad no intrusiva, no mediante el cobro a los usuarios.

¿Cuántas herramientas tiene Logrith?

Actualmente, Logrith cuenta con más de 100 herramientas totalmente funcionales, listas para usar. Se añaden nuevas herramientas periódicamente según la demanda de los usuarios. Las categorías incluyen Imagen y PDF, Cálculo y Conversión, Texto y Generadores, Herramientas para Desarrolladores, Utilidades y Herramientas de IA.

¿Necesito crear una cuenta o iniciar sesión?

No. No se requiere registro, inicio de sesión ni información personal. Todas las herramientas son accesibles de inmediato. No hay ningún formulario de registro en ninguna parte de Logrith.

¿Qué navegadores admite Logrith?

Todos los navegadores modernos: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+ y Brave. Se admiten tanto las versiones de escritorio como las móviles de estos navegadores. Internet Explorer no es compatible, ya que carece de las API web modernas en las que se basan las herramientas Logrith.

Privacidad y seguridad
¿Mis archivos se han subido a los servidores de Logrith?

No. Esto es lo más importante que debes entender sobre Logrith: todo el procesamiento de archivos se realiza completamente en tu navegador mediante las API de JavaScript. Tus imágenes, PDF y documentos nunca se transmiten a ningún servidor. Puedes comprobarlo tú mismo abriendo las Herramientas para desarrolladores de Chrome → pestaña Red y usando cualquier herramienta; verás que no se realizan solicitudes de carga de archivos.

¿Es seguro procesar documentos confidenciales en Logrith?

Sí. Dado que los archivos nunca salen de tu dispositivo, Logrith es seguro para documentos confidenciales: contratos, estados financieros, fotos personales, archivos comerciales confidenciales. El procesamiento se realiza en el entorno JavaScript aislado de tu navegador y los datos nunca son accesibles para nosotros.

¿Recopila Logrith algún dato personal?

Logrith no recopila, almacena ni procesa datos personales ni el contenido de archivos. Utilizamos análisis anónimos estándar (visitas a páginas, patrones de uso generales) para comprender qué herramientas son las más utilizadas. No se almacena ningún dato de usuario individual, el contenido de archivos ni las consultas de búsqueda. Consulte nuestra Política de Privacidad para obtener más información.

¿Puedo usar Logrith sin conexión?

La mayoría de las herramientas funcionan sin conexión una vez que la página se ha cargado, ya que todo el procesamiento es local. Algunas herramientas cargan bibliotecas JavaScript desde una CDN (PDF-Lib, QRCode.js) que requieren una conexión a internet inicial. Una vez cargada la biblioteca, el procesamiento propiamente dicho puede realizarse sin conexión.

Herramientas de imagen
¿Cómo convierto JPG a PNG en Logrith?

Abre la herramienta Convertidor de imágenes, sube tu archivo JPG (arrastra y suelta o haz clic para buscar), selecciona PNG como formato de salida y haz clic en Convertir. La descarga comenzará inmediatamente. También puedes convertir varios archivos a la vez.

¿Cuánto puedo comprimir una imagen sin perder calidad?

Con una calidad del 75-80%, los archivos JPG y WEBP suelen ser entre un 40% y un 70% más pequeños, sin que la diferencia sea perceptible a simple vista. El compresor de imágenes muestra el tamaño exacto de los archivos antes y después de la compresión, así como el porcentaje de ahorro. La compresión PNG es sin pérdidas: elimina los metadatos sin afectar la calidad visual.

¿Qué formatos de imagen son compatibles?

Logrith El convertidor de imágenes admite JPG/JPEG, PNG, WEBP, BMP y GIF. Para la salida, puede convertir a JPG, PNG, WEBP o BMP. El formato HEIC (formato de iPhone) no es compatible directamente con la API Canvas del navegador; primero convierta HEIC a JPG en su teléfono usando las opciones de compartir integradas.

¿Qué es WEBP y por qué debería usarlo?

WEBP es un formato de imagen moderno desarrollado por Google. Genera archivos entre un 25 % y un 34 % más pequeños que los formatos JPG o PNG equivalentes, manteniendo la misma calidad visual. Usar WEBP en tu sitio web mejora directamente las puntuaciones de Google PageSpeed ​​y Core Web Vitals. Todos los navegadores modernos son compatibles con WEBP.

Herramientas PDF
¿Cómo puedo combinar varios archivos PDF?

Abre PDF Merge, sube todos tus archivos PDF, arrástralos para ordenarlos si es necesario y haz clic en «Combinar PDF». La herramienta utiliza PDF-Lib, que se ejecuta en tu navegador, para combinar los archivos. Descarga el PDF combinado al instante. No hay límites de tamaño de archivo más allá de la memoria disponible en tu navegador.

¿Puedo extraer páginas específicas de un PDF?

Sí. En PDF Split, seleccione "Extraer rango de páginas" e introduzca rangos como "1-5, 8, 10-12". La herramienta creará un nuevo PDF con exactamente esas páginas. También puede dividir un PDF en archivos PDF individuales de una sola página utilizando la opción "Dividir todas las páginas".

¿El procesamiento de archivos PDF reducirá la calidad del documento?

No. PDF-Lib copia los objetos de página directamente de los archivos fuente sin recodificarlos. El texto permanece seleccionable, las imágenes conservan su resolución original y se mantiene todo el formato. La fusión, la división y la rotación son operaciones de metadatos que no afectan la calidad del contenido.

¿Cuál es el tamaño máximo de archivo PDF?

Cada archivo PDF tiene un límite de tamaño individual de 20 MB. El tamaño total combinado para las operaciones de fusión depende de la memoria disponible del navegador (normalmente entre 100 y 200 MB en ordenadores de escritorio). Para archivos PDF muy grandes, recomendamos dividirlos primero en fragmentos más pequeños.

Herramientas para desarrolladores
¿El generador de contraseñas es criptográficamente seguro?

Sí. El generador de contraseñas de Logrith utiliza crypto.getRandomValues() (la API Web Crypto), que proporciona una aleatoriedad criptográficamente segura equivalente a la que utilizan los sistemas operativos y el software de seguridad. No se trata de la función Math.random(), que es débil, utilizada por muchos sitios generadores.

¿Puedo aplicar hash a archivos, no solo a texto?

Sí. El generador de hashes admite archivos de hasta 100 MB. Utiliza SubtleCrypto.digest() para calcular hashes SHA-1, SHA-256, SHA-384 y SHA-512. El cálculo de hashes de archivos es útil para verificar la integridad de la descarga: compare el hash con el proporcionado por el editor del software.

¿El formateador JSON funciona con archivos grandes?

El formateador JSON funciona con archivos de hasta 50-100 MB, dependiendo de la memoria disponible en tu dispositivo. Para archivos JSON muy grandes, utiliza la herramienta de línea de comandos jq. Para respuestas de API y archivos de configuración típicos, el formateador maneja archivos de cualquier tamaño sin problemas.

Técnico
Una herramienta no funciona, ¿qué debo hacer?

1) Intenta actualizar la página. 2) Borra la caché del navegador (Ctrl+Mayús+R). 3) Si usas otro navegador, prueba con Chrome o Firefox. 4) Comprueba que el archivo no supere el límite de tamaño. 5) Si el problema persiste, infórmanos a través de nuestra página de Contacto, indicando el nombre de la herramienta y lo sucedido. Solucionamos los errores en un plazo de 48 horas.

¿Por qué algunas herramientas necesitan internet aunque sean del lado del cliente?

Algunas herramientas cargan bibliotecas JavaScript (PDF-Lib, PDF.js, QRCode.js) desde una CDN la primera vez que se usan. Una vez descargadas las bibliotecas, el procesamiento se realiza localmente. Después de visitar la página de una herramienta, la mayoría funciona sin conexión gracias al almacenamiento en caché del navegador. Las herramientas basadas exclusivamente en JavaScript (herramientas de texto, calculadoras, formateadores JSON) funcionan completamente sin conexión desde la primera visita.

¿Puedo usar las herramientas Logrith mediante programación a través de la API?

Logrith es una plataforma exclusivamente web; no dispone de una API pública. Para acceder mediante programación, utilice las mismas bibliotecas que nosotros: PDF-Lib (npm), Sharp (procesamiento de imágenes con Node.js) y la API Web Crypto directamente en su código JavaScript. El desarrollo de una API está previsto a largo plazo.
