Por qué existe esta página

Las herramientas de Logrith están escritas casi en su totalidad en JavaScript puro, sin ningún framework complejo. Para algunos problemas realmente complejos —leer y escribir archivos PDF, convertir páginas PDF en imágenes, generar códigos QR escaneables— utilizamos un pequeño número de bibliotecas de código abierto específicas y bien mantenidas, en lugar de reinventar el trabajo desde cero. Esta página tiene como objetivo ser transparente sobre qué bibliotecas se utilizan, qué hacen y bajo qué licencia, para que cualquiera que audite las dependencias de la plataforma pueda verificarlo directamente.

Todas las bibliotecas mencionadas anteriormente se utilizan bajo su licencia de código abierto original, sin modificaciones. No realizamos bifurcaciones, no rentabilizamos ni reclamamos la autoría de ningún código de terceros; los enlaces de crédito y licencia que aparecen arriba remiten a la fuente original para que usted mismo pueda verificar los términos.

Preguntas sobre licencias

¿Puedo utilizar la salida de Logrith con fines comerciales?

Yes. Anything you create using a Logrith tool — a compressed image, a merged PDF, a generated QR code — is yours to use however you like, including commercially. The open source licenses on this page cover the libraries that power the tools, not the files you produce with them.

¿Puedo reutilizar el diseño o el código fuente de Logrith?

El nombre, el logotipo, el diseño de la interfaz y el código fuente original de Logrith son propiedad de la empresa, como se indicó anteriormente. Las bibliotecas de código abierto de las que dependemos pueden ser utilizadas por cualquier persona bajo sus propias licencias, pero no mediante la copia directa del código fuente de Logrith.

¿Qué ocurre si cambia la licencia de una dependencia o se actualiza una biblioteca?

Esta página se actualiza cada vez que cambia el conjunto de bibliotecas Logrith. Si encuentras algo que parezca desactualizado, la página de Contacto es la forma más rápida de informarnos.
