About Logrith Developer Tools

Las herramientas para desarrolladores son utilidades que programadores, ingenieros de DevOps y usuarios técnicos necesitan constantemente, pero no deberían requerir la instalación de software ni la suscripción a servicios para acceder a ellas. La colección de herramientas para desarrolladores de Logrith incluye las utilidades más utilizadas, todas funcionando en el navegador sin necesidad de configuración.

El formateador JSON es una de las herramientas más utilizadas: valida JSON con localización precisa de errores, mejora la legibilidad del JSON minimizado y minimiza el JSON formateado para su uso en producción. La función de ordenación de claves es especialmente útil para estandarizar los formatos de respuesta de la API y los archivos de configuración.

Para tareas que requieren alta seguridad, Logrith utiliza la API Web Crypto integrada del navegador, las mismas primitivas criptográficas que usa el propio sistema operativo. El generador de hashes utiliza SubtleCrypto.digest() para SHA-256/SHA-512, y el generador de contraseñas utiliza crypto.getRandomValues() para generar números aleatorios con seguridad criptográfica. Ninguna de las dos herramientas tiene dependencias externas para su funcionamiento principal.

El probador de expresiones regulares utiliza el motor de expresiones regulares nativo del navegador (el mismo que usará tu Node.js o JavaScript de frontend), por lo que los resultados de las pruebas coinciden exactamente con los que obtendrías en código JavaScript de producción. Esta es una ventaja clave sobre los probadores de expresiones regulares basados ​​en servidor que pueden usar diferentes variantes de expresiones regulares (PCRE, Python re, etc.).

Preguntas frecuentes

¿Qué algoritmo hash debo usar para almacenar contraseñas?

Ninguno de los algoritmos hash de esta herramienta (SHA-256, SHA-512) es adecuado para almacenar contraseñas, ya que son demasiado rápidos, lo que facilita los ataques de fuerza bruta. Para el cifrado de contraseñas, utilice bcrypt, Argon2id o scrypt con un alto factor de coste. Estas herramientas se utilizan para sumas de comprobación, verificación de la integridad de los datos y otros usos no relacionados con la seguridad.

¿Es seguro el formateador JSON para datos confidenciales de API?

Sí. Todo el procesamiento JSON se realiza únicamente en la memoria del navegador; no se envía ningún dato a ningún servidor. Incluso puedes desconectarte de internet después de cargar la página y el formateador seguirá funcionando perfectamente.

¿Cuál es la diferencia entre encodeURIComponent y encodeURI?

`encodeURI` codifica una URL completa, conservando caracteres como `/`, `?`, `&`, `=` y `#` que tienen significado estructural. `encodeURIComponent` codifica todo excepto los caracteres no reservados; úselo para valores dentro de parámetros de consulta. Para valores de cadena de consulta, utilice siempre `encodeURIComponent`.

¿Puedo usar estas herramientas en un pipeline de CI/CD?

Estas herramientas son web e interactivas; están diseñadas para uso manual. Para pipelines de CI/CD, utilice herramientas de línea de comandos como jq (JSON), openssl (hashing) o uuidgen. Logrith está diseñado para facilitar el trabajo del desarrollador en el navegador, no para la automatización mediante scripts.

¿Cómo puedo probar una expresión regular que debería coincidir con direcciones de correo electrónico?

Abre el probador de expresiones regulares y haz clic en el botón " Email" en la sección de patrones comunes para cargar una expresión regular estándar para correo electrónico. Luego, modifica tu cadena de prueba. Puedes ajustar la expresión regular directamente; todas las coincidencias se resaltan en tiempo real mientras escribes.

¿Qué variante de Base64 debo usar para los tokens JWT?

Los tokens JWT utilizan Base64 seguro para URL (Base64url), que reemplaza + por - y / por _, y omite los caracteres de relleno =. Seleccione "Base64 seguro para URL" en el menú desplegable de modo de codificación de la herramienta Base64. La variante estándar (+/=) no debe usarse directamente en URL ni en encabezados HTTP.

¿Qué es UUID v4 y cuándo debo usarlo?

UUID v4 es un identificador de 128 bits generado aleatoriamente con el formato xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx. Úselo como clave primaria de base de datos, token de sesión, nombre de archivo o cualquier identificador que requiera unicidad sin coordinación central. La probabilidad de colisión es insignificante: aproximadamente 1 entre 5,3 × 10³⁶.

¿Qué tan precisas son las estimaciones del tiempo necesario para descifrar una contraseña?

Las estimaciones se basan en ataques de fuerza bruta puros a través de todo el espacio de claves. Los ataques reales suelen utilizar ataques de diccionario y generación basada en reglas, que permiten descifrar patrones comunes mucho más rápido. Las estimaciones proporcionan un límite superior teórico; en la práctica, cualquier contraseña basada en palabras de diccionario o patrones comunes es mucho más débil de lo que sugiere el cálculo basado en la entropía.

¿Puedo formatear archivos JSON muy grandes?

El formateador JSON funciona con cualquier tamaño que quepa en la memoria del navegador; normalmente, admite hasta 50-100 MB de texto JSON sin problemas en dispositivos modernos. Los archivos JSON muy grandes (cientos de MB) pueden provocar que se alcancen los límites de memoria de la pestaña del navegador. Para archivos extremadamente grandes, utilice jq en la línea de comandos.

¿Hay planes para añadir un formateador HTML o un formateador XML?

Sí, tanto el formateador HTML como el XML están previstos. El formateador HTML utilizará el DOMParser del navegador para analizar y serializar el código con la indentación adecuada. De forma similar, el formateador XML aprovechará las capacidades de procesamiento XML nativas del DOMParser para obtener resultados compatibles con el navegador.
