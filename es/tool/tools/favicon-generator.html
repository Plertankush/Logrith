Preguntas frecuentes

¿Qué tamaños de favicon necesito?

Los sitios web modernos suelen necesitar 16×16 y 32×32 píxeles para las pestañas del navegador, 180×180 píxeles para el icono táctil de Apple y 192×192 píxeles más 512×512 píxeles para las pantallas de inicio de Android y los manifiestos de las PWA.

¿Qué imagen debo subir?

Lo mejor es usar una imagen cuadrada, idealmente de al menos 512×512 píxeles, con un diseño sencillo y reconocible, ya que los favicons se muestran muy pequeños.

¿Necesito específicamente un archivo .ico?

La mayoría de los navegadores modernos aceptan iconos PNG a través de etiquetas de enlace, pero un favicon.ico clásico sigue siendo una buena alternativa para los navegadores más antiguos.

¿Mi imagen está subida a algún sitio?

No. Todos los cambios de tamaño se realizan localmente en tu navegador mediante la API de Canvas; no se sube nada a un servidor.

Cómo usar el generador de favicon

  1. Sube una imagen de origen

    Arrastra un archivo PNG o JPG a la zona de carga; idealmente, debe tener un tamaño mínimo de 512×512 píxeles para obtener resultados nítidos en cualquier tamaño.

    Recorta automáticamente la imagen centrándola a un cuadrado y la renderiza en tamaños de 16×16, 32×32, 48×48, 180×180, 192×192 y 512×512.

  3. Descarga los tamaños individualmente o todos a la vez.

    Haz clic en Descargar debajo del tamaño que necesites, o usa Descargar todos los tamaños para guardar todas las imágenes PNG con un solo clic.

  4. Copia el fragmento HTML en tu sitio web.

    Pega las etiquetas de enlace generadas en la sección <head> de tu página para que los navegadores y dispositivos detecten automáticamente el icono correcto.

¿Por qué hay tantos tamaños de favicon?

Los favicons ya no se limitan a las pestañas del navegador. Las distintas plataformas y contextos requieren tamaños diferentes: las pestañas del navegador suelen usar 16×16 o 32×32, los marcadores de la pantalla de inicio de iOS usan un icono táctil de 180×180, y los manifiestos de Android y las aplicaciones web progresivas suelen solicitar versiones de 192×192 y 512×512 para los iconos de la pantalla de inicio y las instalaciones tipo aplicación. Ofrecer todos estos tamaños garantiza que el icono de tu sitio se vea nítido en cualquier lugar donde aparezca, en lugar de verse distorsionado o borroso a partir de una sola imagen pequeña.

Consejos para una buena imagen de origen del favicon

  • Empieza con un cuadrado. Una imagen que no sea cuadrada se generará como cuadrada de todos modos, así que recortarla a una proporción de 1:1 te da control total sobre la composición.
  • Mantén la sencillez. Los favicons se visualizan en un tamaño extremadamente pequeño; los detalles intrincados o el texto pequeño se convierten en una mancha ilegible a 16×16.
  • Utilice una fuente de alta resolución. Partir de al menos 512×512 píxeles garantiza que el tamaño máximo generado se mantenga nítido, ya que ampliar una imagen pequeña (en lugar de reducirla) siempre introduce desenfoque.
  • Considere usar un fondo transparente si su favicon necesita funcionar tanto en temas claros como oscuros del navegador.

Cómo funciona esta herramienta

Tras subir una imagen, la herramienta la carga en un lienzo HTML y la redibuja en cada tamaño deseado utilizando el suavizado de imagen integrado del lienzo, generando una imagen PNG nítida y reducida para cada dimensión. Dado que todo esto se realiza a través de la API de Canvas directamente en tu navegador, no hay subida de archivos, ni retrasos en el procesamiento del servidor, ni problemas de privacidad: la imagen original nunca sale de tu dispositivo.

Agregar los favicons generados a su sitio web.

Una vez generados, descarga cada tamaño y coloca los archivos en la carpeta raíz o de recursos de tu sitio web. Luego, pega el fragmento HTML proporcionado en la sección <head> de tu página. Esto incluye etiquetas <link rel="icon"> estándar para los tamaños de pestañas del navegador, un enlace apple-touch-icon para iOS y referencias adecuadas para un archivo site.webmanifest si estás creando una aplicación web instalable.

Privacidad y procesamiento local

Todos los cambios de tamaño se realizan localmente mediante la API de Canvas; la imagen nunca se sube a ningún servidor, lo que mantiene los logotipos o la marca no publicados completamente privados hasta que estés listo para publicarlos.

Cómo se gestionan las imágenes no cuadradas

Si subes una imagen rectangular, la herramienta la recorta automáticamente del centro al cuadrado más grande posible antes de redimensionarla, en lugar de comprimirla para que encaje. Esto mantiene el centro de la imagen intacto y evita la distorsión que causaría el estiramiento, pero implica que el contenido cercano a los bordes superior, inferior, izquierdo o derecho de una imagen no cuadrada podría recortarse. Por lo tanto, para tener un control total sobre la composición, recorta la imagen a un cuadrado antes de subirla.

Dónde se utiliza cada tamaño de favicon

  • 16×16 y 32×32: se muestran en las pestañas del navegador, las barras de marcadores y las listas del historial del navegador; son los tamaños que se ven con más frecuencia.
  • 48×48: utilizado por algunos accesos directos a sitios web de Windows y elementos de la interfaz de usuario de navegadores antiguos.
  • 180×180 (icono táctil de Apple): se muestra cuando un usuario agrega tu sitio a la pantalla de inicio de su dispositivo iOS o iPadOS.
  • 192×192: tamaño estándar de los iconos de la pantalla de inicio de Android y del manifiesto de las PWA de Chrome.
  • 512×512: se utiliza para las pantallas de inicio de Android y como fuente de alta resolución para las indicaciones de instalación de PWA.

Para desarrolladores: Dónde colocar los archivos

La mayoría de los frameworks esperan que los archivos favicon se encuentren en una carpeta pública o de recursos estáticos ubicada en la raíz del sitio; por ejemplo, en /public en un proyecto de React o Next.js, o en /static en muchos generadores de sitios estáticos. El fragmento HTML generado hace referencia a rutas absolutas como /favicon-32x32.png, por lo que basta con subir los archivos descargados al directorio raíz del sitio (o ajustar las rutas para que coincidan con la estructura de carpetas) para que funcionen correctamente.

Generador de favicon vs. Redimensionamiento manual

Redimensionar manualmente un logotipo en seis archivos separados en un editor de imágenes implica repetir los mismos pasos de recorte y exportación seis veces, controlando las dimensiones exactas en píxeles y escribiendo manualmente las etiquetas HTML de los enlaces. Esta herramienta realiza el recorte centrado, el redimensionamiento y el suavizado para cada tamaño requerido en una sola pasada y genera automáticamente el HTML correspondiente, reduciendo una tarea repetitiva de 15 a 20 minutos a tan solo unos segundos.

Errores comunes que se deben evitar

  • Subir una fuente de baja resolución: empezar con una resolución inferior a 512×512 significa que los tamaños generados más grandes se verán borrosos, ya que el escalado ascendente introduce un desenfoque que el escalado descendente evita.
  • Al usar un logotipo recargado o detallado, los detalles finos, las líneas delgadas o el texto pequeño desaparecen en 16×16; los favicons funcionan mejor como formas simples y llamativas o una sola letra/marca.
  • Olvidar la referencia del manifiesto: si estás creando una PWA instalable, asegúrate de que tu archivo site.webmanifest también haga referencia a los iconos de 192×192 y 512×512, no solo a las etiquetas HTML <link>.
