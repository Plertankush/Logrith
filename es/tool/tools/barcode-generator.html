¿Qué es CODE128?

CODE128 es uno de los formatos de código de barras lineales más utilizados, capaz de codificar el conjunto completo de caracteres ASCII (letras, números y símbolos) con alta densidad. Se encuentra comúnmente en etiquetas de envío, empaques de productos y etiquetas de inventario debido a su compacidad y confiabilidad. A diferencia de formatos más simples como Code39, CODE128 incluye un dígito de control obligatorio calculado a partir de los datos codificados, lo que ayuda a los escáneres a detectar y rechazar códigos de barras mal leídos.

Cómo esta herramienta genera un código de barras válido

Cada carácter introducido se asigna a un valor numérico según el estándar CODE128 Subconjunto B, y se calcula una suma de verificación sumando cada valor multiplicado por su posición y, a continuación, calculando el resultado módulo 103, tal como lo exige la especificación CODE128. Este valor de suma de verificación se añade a la secuencia codificada, junto con los patrones de inicio y fin obligatorios, lo que garantiza que el código de barras resultante cumpla con el estándar y sea legible por cualquier escáner de códigos de barras real, y no solo una aproximación visual.

Comprensión del subconjunto B de CODE128

CODE128 cuenta con tres subconjuntos (A, B y C) optimizados para distintos tipos de datos. El subconjunto C agrupa pares de dígitos para una codificación numérica muy densa, mientras que los subconjuntos A y B abarcan todo el rango ASCII imprimible con diferente compatibilidad con caracteres de control. Esta herramienta utiliza el subconjunto B, que incluye todas las letras mayúsculas y minúsculas estándar, dígitos y signos de puntuación comunes (valores ASCII del 32 al 126), lo que lo convierte en la opción ideal para códigos alfanuméricos de uso general, como SKU de productos, nombres y números de referencia de formato mixto, en lugar de cadenas numéricas largas.

Cómo la suma de verificación evita errores de lectura

Cada código de barras CODE128 válido incluye un carácter de suma de verificación calculado a partir de los datos que codifica. Esta herramienta lo calcula tomando el valor del código de inicio, sumando el valor de cada carácter subsiguiente multiplicado por su posición en la secuencia y restando el total módulo 103. Un escáner recalcula esta misma suma de verificación a partir de lo que lee y la compara con la suma de verificación codificada en el código de barras. Si no coinciden, el escáner rechaza la lectura en lugar de informar datos incorrectos, razón por la cual una suma de verificación calculada correctamente (como la que produce esta herramienta) es importante para la fiabilidad en el mundo real, no solo para la apariencia visual.

Por qué esto produce un código de barras escaneable, no solo una imagen.

Un código de barras no es simplemente una sucesión de rayas blancas y negras dispuestas de forma que parezcan correctas; cada carácter se corresponde con uno de los 107 patrones precisos de barras y espacios de 11 bits definidos por la especificación CODE128. La secuencia debe comenzar con un patrón de inicio válido y terminar con el patrón de parada estándar para que un escáner la reconozca. Esta herramienta busca cada valor codificado en la tabla de patrones oficial de CODE128 y renderiza las barras píxel a píxel según ese patrón, en lugar de generar una imagen similar a un código de barras que solo se asemeja a uno real. Esto significa que el resultado puede ser escaneado por hardware y aplicaciones de escaneo reales, y no solo mostrado como referencia visual.

Cómo elegir el ancho y la altura de la barra.

El ancho de las barras controla la cantidad de píxeles de ancho de cada barra unitaria: las barras más delgadas crean un código de barras más compacto, pero requieren un escáner o impresora de mayor resolución para una lectura fiable, mientras que las barras más gruesas toleran mejor las impresiones de menor calidad o el escaneo con la cámara del teléfono, pero producen una imagen más ancha. La altura es principalmente una cuestión de legibilidad y estética, ya que CODE128 es un formato 1D (lineal) que se lee horizontalmente, aunque las barras más altas facilitan que un escáner portátil obtenga una lectura limpia si el ángulo de escaneo no es perfectamente horizontal.

Personajes compatibles y no compatibles

El subconjunto B de CODE128, tal como se implementa aquí, admite caracteres ASCII imprimibles estándar: letras mayúsculas y minúsculas, dígitos del 0 al 9, espacios y signos de puntuación y símbolos comunes en un teclado estándar. Los caracteres que no se encuentran dentro de este rango imprimible (como caracteres Unicode extendidos, emojis o ciertos caracteres de control) no son compatibles y generarán un mensaje de error que indicará el carácter específico no compatible, para que pueda ajustar su entrada en lugar de obtener un código de barras defectuoso sin mostrar ningún mensaje de error.

CODE128 frente a otros formatos de código de barras

CODE128 es más denso que formatos anteriores como Code39, lo que significa que puede codificar los mismos datos en una longitud física menor, algo importante cuando el espacio en la etiqueta es limitado. Se diferencia de los formatos UPC/EAN utilizados en los envases de venta al por menor, que son códigos numéricos de longitud fija vinculados a un sistema de registro de productos (GS1) en lugar de texto arbitrario. CODE128 es más adecuado para códigos de referencia internos, números de seguimiento y etiquetas de activos donde se controla tanto la codificación como el escaneo, en lugar de para códigos de barras de punto de venta que deben coincidir con un número de producto registrado.
