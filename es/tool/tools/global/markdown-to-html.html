Cómo convertir Markdown a HTML

  1. Pegue o escriba su texto Markdown en el cuadro de entrada.

  2. Haz clic en "Convertir a HTML" para procesarlo con el analizador.

  3. Cambia entre la pestaña "Vista previa en vivo" para ver el resultado renderizado y la pestaña "Código fuente HTML" para ver el marcado generado.

  4. Haz clic en "Copiar HTML" para copiar el código o en "Descargar .html" para guardarlo como un archivo HTML completo e independiente.

¿Qué funciones admite este convertidor?

  • Encabezados: los seis niveles, desde # hasta ######.
  • Formato de texto: negrita (**text** o __text__) y cursiva (*text* o _text_).
  • Listas: listas no ordenadas con -, * o +, y listas ordenadas con 1., 2., y así sucesivamente.
  • Enlaces e imágenes: [text](url) y ![alt](url).
  • Código: bloques de código en línea `code` y delimitados mediante tres comillas invertidas, con caracteres especiales escapados por seguridad.
  • Citas en bloque, líneas horizontales y tablas: citas >, reglas --- y tablas delimitadas por barras verticales con una fila de alineación.

¿Qué es Markdown?

Markdown es una sintaxis de formato de texto plano ligera creada para que los usuarios puedan escribir documentos formateados utilizando únicamente un editor de texto plano. En lugar de hacer clic en los botones de la barra de herramientas para poner texto en negrita o insertar un encabezado, se escribe un pequeño conjunto de símbolos —un # antes de una línea para un encabezado, asteriscos alrededor de una palabra para enfatizarla, un guion para un elemento de lista— y un procesador de Markdown convierte ese texto plano en HTML con la estructura adecuada. Dado que se lee casi como prosa incluso antes de la conversión, Markdown se ha convertido en el formato de escritura predeterminado para archivos README en plataformas de alojamiento de código, documentación técnica, blogs de desarrolladores, generadores de sitios estáticos, aplicaciones para tomar notas y plataformas de chat que admiten texto enriquecido.

¿Por qué convertir Markdown a HTML?

Markdown es excelente para escribir, pero los navegadores no lo renderizan directamente, sino que renderizan HTML. Convertir Markdown a HTML es el paso que transforma tu borrador de texto plano en algo que un navegador, un sistema de gestión de contenido o un cliente de correo electrónico pueda mostrar con encabezados adecuados, listas formateadas, enlaces clicables y bloques de código con estilo. Esta conversión se realiza constantemente en segundo plano: los generadores de sitios estáticos convierten los archivos fuente de Markdown en páginas HTML durante la compilación, las plataformas de alojamiento de código convierten los archivos README.md en páginas formateadas sobre la marcha, y muchas plataformas de blogs aceptan Markdown específicamente para convertirlo a HTML antes de publicarlo. Disponer de un convertidor independiente es útil siempre que quieras ver o reutilizar ese HTML directamente; por ejemplo, pegar contenido formateado en un sistema de gestión de contenido que no entiende Markdown, generar rápidamente una página HTML independiente a partir de notas o comprobar exactamente qué marcado producirá tu Markdown antes de incorporarlo a un proyecto.

Qué significa "HTML limpio y semántico"

El HTML semántico implica usar el elemento HTML que realmente coincide con el significado del contenido, en lugar de etiquetas de estilo genéricas. Un encabezado se convierte en un

Primero, la accesibilidad: los lectores de pantalla y otras tecnologías de asistencia dependen de las etiquetas semánticas para anunciar la estructura; un lector de pantalla le dice a un usuario "encabezado nivel 2" o "lista, 4 elementos" solo cuando el marcado subyacente es realmente un encabezado o un elemento de lista. Segundo, los motores de búsqueda usan la jerarquía de encabezados y el marcado estructural como señales al indexar y resumir una página, por lo que la salida semántica tiende a ser más accesible y más amigable para la búsqueda que el marcado visualmente similar pero estructuralmente plano.

      Cómo funciona esta herramienta

      El convertidor ejecuta un analizador sintáctico manual directamente en tu navegador, en dos etapas. La primera etapa analiza el Markdown línea por línea para identificar estructuras de nivel de bloque: encabezados, bloques de código delimitados, citas, líneas horizontales, bloques de lista, bloques de tabla y párrafos normales. La segunda etapa procesa el texto en línea dentro de cada bloque que no sea de código, aplicando formato de negrita, cursiva, código en línea y enlaces o imágenes. Además, los caracteres especiales dentro de los bloques de código y los fragmentos de código en línea se escapan para que los corchetes angulares y las ampersands en tu código de ejemplo se muestren como texto visible en lugar de interpretarse como etiquetas HTML. Todo sucede de forma síncrona, sin necesidad de conexión a la red, por lo que la vista previa en tiempo real se actualiza en cuanto haces clic en convertir, y tu contenido nunca abandona la página.

      Casos de uso comunes

      • Cómo escribir un archivo README: redacta el archivo README del proyecto en Markdown y, a continuación, comprueba exactamente cómo se mostrará como HTML antes de publicarlo en otro sitio.
      • Convertir notas en una entrada de blog: transforma notas de texto plano escritas en Markdown en código HTML listo para pegar en una plataforma de blogs o un sistema de gestión de contenido.
      • Preparación de contenido para un CMS: muchos sistemas de gestión de contenido aceptan HTML sin formato en un bloque de código o de inserción; convertir primero el código Markdown permite pegar directamente el contenido formateado.
      • Generación de una página HTML independiente: escriba un documento breve en Markdown y descárguelo como un archivo HTML5 completo y válido que podrá abrir en cualquier navegador.
      • Comprobación de la salida de tablas y listas: verifique que una tabla o lista anidada de Markdown se convierta a HTML con la estructura correcta antes de usarla en la documentación.

      ¿Por qué un analizador sintáctico escrito a mano?

      Muchos convertidores en línea simplemente cargan una biblioteca Markdown de terceros desde una red de distribución de contenido. Esta herramienta, en cambio, utiliza un analizador sintáctico escrito específicamente para Logrith, sin dependencias externas, lo que mantiene la página ligera y completamente funcional incluso si no se puede acceder a una CDN. Admite la sintaxis básica de estilo CommonMark que la mayoría de la gente usa a diario (encabezados, énfasis, listas, enlaces, imágenes, código, citas, reglas y tablas), en lugar de intentar replicar todos los casos excepcionales de la especificación completa de Markdown.

Preguntas frecuentes sobre el convertidor de Markdown a HTML

¿Qué sintaxis de Markdown admite este convertidor?

Admite encabezados, texto en negrita y cursiva, listas ordenadas y desordenadas, enlaces, imágenes, código en línea, bloques de código delimitados, citas en bloque, líneas horizontales, tablas y párrafos con saltos de línea.

¿Esta herramienta sube mi archivo Markdown a algún sitio?

No. La conversión completa se realiza localmente en tu navegador mediante un analizador JavaScript escrito manualmente. Tu texto nunca se envía a Logrith ni a ningún otro servidor.

¿Utiliza alguna biblioteca Markdown externa?

No. El analizador sintáctico está escrito desde cero en JavaScript puro, sin dependencias externas, por lo que la herramienta se carga rápidamente y funciona completamente sin conexión una vez que se abre la página.

¿Es seguro reutilizar el código HTML generado?

El texto dentro de los bloques de código y el código en línea se codifica para que los corchetes angulares y las ampersands se muestren literalmente en lugar de interpretarse como marcado. El HTML generado refleja las convenciones estándar de Markdown a HTML y es adecuado para pegarlo en un blog, un sitio estático o una página de documentación.

¿Puedo descargar el HTML como un archivo completo?

Sí. El botón de descarga envuelve el HTML convertido en un documento HTML5 mínimo y válido con un doctype, charset y título, listo para guardar como un archivo .html independiente.
