Herramienta de reparación de JSON: corrige y valida JSON.

Pega el JSON dañado, valídalo, corrige automáticamente los errores de sintaxis comunes y formatea, minimiza o convierte el resultado, todo ello directamente en tu navegador.

Pega tu JSON

Tu JSON se procesa en tu navegador. Los datos no se suben a Logrith.

Cómo corregir JSON

  1. Pegue o escriba su JSON en el cuadro de entrada de arriba.

  2. Haz clic en "Validar" para comprobarlo, o haz clic directamente en "Reparación automática" si sabes que tiene errores comunes.

  3. Si la reparación se realiza correctamente, revise las correcciones aplicadas y, a continuación, haga clic en "Aceptar JSON reparado" para reemplazar el contenido del editor.

  4. Utilice "Formato" para embellecer el resultado, "Minimizar" para comprimirlo o cambie de pestaña para verlo como un árbol, una interfaz TypeScript o un archivo CSV.

¿Qué hace esta herramienta de reparación de JSON?

  • Validación: analiza su JSON e informa la línea y columna exactas del primer error de sintaxis.
  • Reparación automática: corrige las comas finales, las claves de objetos sin comillas y los valores de cadena entre comillas simples cuando puede hacerlo de forma segura.
  • Formato: embellece el JSON con una sangría seleccionable de 2 espacios, 4 espacios o una tabulación.
  • Minificación: elimina todos los espacios en blanco innecesarios para obtener una salida compacta.
  • Vista de árbol: muestra el JSON analizado como una estructura anidada desplegable que puedes explorar.
  • Conversiones: genera una interfaz TypeScript o, para datos de tipo array de objetos, un archivo CSV.

¿Qué es JSON?

JSON (JavaScript Object Notation) es un formato de datos ligero, basado en texto, que se utiliza prácticamente en todas partes en el software moderno: respuestas de API, archivos de configuración, ajustes de aplicaciones, exportaciones de datos y la salida de innumerables herramientas y scripts. Representa los datos como objetos anidados (pares clave-valor entre llaves) y matrices (listas ordenadas entre corchetes), con valores que pueden ser cadenas de texto, números, booleanos, nulos o incluso objetos y matrices anidados. Su simplicidad es precisamente la razón de su amplio uso, y también la razón por la que una sola coma faltante o una comilla suelta pueden hacer que un analizador sintáctico lea un archivo completo.

¿Por qué JSON se vuelve inválido?

JSON tiene reglas de sintaxis estrictas e implacables. A diferencia de algunos formatos de configuración que toleran pequeñas inconsistencias, un analizador JSON rechazará todo el documento por un solo carácter mal colocado. Las causas más comunes de JSON no válido son:

  • Faltan comas entre las propiedades o los elementos de la matriz.
  • Faltan comillas alrededor de los valores de cadena o las claves de objeto.
  • Comas adicionales al final del último elemento de un objeto o matriz: válidas en literales de objetos de JavaScript, pero no en JSON estricto.
  • Corchetes o soportes que no coinciden debido a un copiar y pegar que recortó parte de la estructura.
  • Valores incorrectos , como usar comillas simples en lugar de comillas dobles, o escribir undefined en lugar de null.

Cómo corregir JSON

La forma más fiable de corregir JSON es dejar que un analizador te indique la ubicación exacta del problema, en lugar de revisar todo el documento manualmente. Esta herramienta lo hace de dos maneras: el botón Validar informa la línea y columna precisas del primer error que encuentra el analizador JSON del navegador, y el botón Autorreparar intenta corregir las categorías específicas de errores que son lo suficientemente comunes como para manejarlas de forma segura y predecible.

Validador JSON

Haz clic en "Validar" para procesar tu entrada con JSON.parse(). Si la validación es exitosa, verás una confirmación de que el JSON es válido. Si falla, el mensaje de error del navegador se analiza para obtener la posición del carácter. Si está presente, esa posición se convierte en un número de línea y columna contando los caracteres de salto de línea en tu entrada hasta ese punto, para que puedas ir directamente al carácter problemático en lugar de releer todo el documento.

Formateador y embellecedor de JSON

Haz clic en "Formato" para formatear JSON válido con una sangría uniforme. Antes de formatear, elige 2 espacios, 4 espacios o una tabulación en el selector de sangría. Esto resulta útil para que las respuestas de API minimizadas o los valores de configuración de una sola línea sean legibles, o para estandarizar el estilo de un archivo antes de subirlo a un repositorio.

Minificador JSON

Haz clic en "Minimizar" para eliminar los espacios en blanco no esenciales de un JSON válido, obteniendo así la representación más pequeña posible. Esto resulta útil cuando necesitas pegar JSON en un campo con límite de tamaño, insertarlo en un parámetro de URL o reducir el tamaño de una carga útil de configuración antes de enviarla por la red.

Reparación de JSON

El botón de Autorreparación aplica tres correcciones específicas y bien definidas, en orden, y vuelve a validar después de cada pasada:

  • Eliminación de la coma final: se elimina la coma que precede directamente a la sección de cierre } o ].
  • Citas de claves sin comillas: una clave de objeto escrita sin comillas (un identificador JavaScript válido seguido de dos puntos) se encierra entre comillas dobles. Las claves que ya están entre comillas permanecen sin cambios.
  • Conversión de comillas simples: los valores de cadena encerrados entre comillas simples se convierten en cadenas entre comillas dobles.

Tras aplicar estas correcciones, la herramienta vuelve a analizar el resultado. Si lo hace correctamente, verá una lista que indica exactamente cuáles de las tres correcciones modificaron el código y un botón para aceptar el JSON corregido en el editor. Si el JSON sigue sin analizarse correctamente, la herramienta le indicará claramente que la reparación automática no pudo solucionarlo y le mostrará el último error de análisis para que pueda corregirlo manualmente.

Limitaciones honestas: este paso de reparación no puede recuperar datos que realmente faltan (como un valor que nunca se escribió), no puede corregir estructuras profundamente mal formadas o truncadas con múltiples problemas superpuestos, no puede adivinar su intención cuando una clave o un valor son ambiguos, y la conversión de comillas simples utiliza un patrón con ámbito que no manejará perfectamente todos los casos de comillas escapadas dentro de una cadena. Está diseñado para corregir de manera confiable los pocos errores que representan la mayoría de los JSON "casi válidos", no para reparar texto roto arbitrariamente.

Casos de uso para desarrolladores

Esta herramienta está diseñada para los momentos cotidianos en que los desarrolladores se topan con JSON defectuoso:

  • Depuración de respuestas de API que no se pueden analizar debido a un error de formato del servidor.
  • Limpiar archivos de configuración editados manualmente por alguien que utilizó la sintaxis de objetos JavaScript en lugar de JSON estricto.
  • Trabajar con la salida JSON generada por IA , que con frecuencia incluye comas al final, claves sin comillas o comillas simples cuando un modelo aproxima JSON a partir de patrones de entrenamiento en lugar de una sintaxis estricta.
  • Intercambio rápido de datos entre herramientas que esperan convenciones JSON ligeramente diferentes.
  • En el desarrollo web , un archivo JSON de datos simulados o un archivo de datos de prueba con formato incorrecto puede bloquear las pruebas locales hasta que se solucione.
  • Generación de tipos y exportaciones tabulares directamente a partir de una carga útil JSON sin necesidad de escribir un script específico.

JSON a TypeScript

Una vez que el JSON se haya analizado correctamente, cambie a la pestaña TypeScript para generar una interfaz básica. La herramienta infiere el tipo de cada campo (cadena, número, booleano o null) y realiza un recorrido recursivo en objetos anidados para generar interfaces con nombre adicionales, y en matrices para inferir el tipo de un elemento a partir del primer elemento. Una matriz vacía se anota como any[] con un comentario que indica que no se pudo inferir su tipo, ya que no hay ningún elemento que examinar.

JSON a CSV

La pestaña CSV funciona específicamente con JSON con formato de matriz de objetos planos, el formato común para registros exportados o respuestas de listas de API. La herramienta crea una fila de encabezado a partir de la unión de todas las claves presentes en todos los objetos, en el orden en que aparecen por primera vez. A continuación, escribe una fila por objeto con el formato CSV adecuado (entrecomillando cualquier valor que contenga una coma, una comilla simple o un salto de línea, y duplicando las comillas internas). Si su JSON no tiene este formato, la herramienta explica claramente por qué no está disponible la exportación a CSV, en lugar de generar un archivo incompleto.

Preguntas frecuentes sobre la herramienta de reparación JSON

¿Puede esta herramienta corregir cualquier JSON dañado?

No. El paso de reparación automática se centra en tres problemas comunes y bien definidos: comas al final de las líneas, claves de objeto sin comillas y valores de cadena entre comillas simples. No puede recuperar datos que realmente falten, corregir estructuras profundamente mal formadas o truncadas, ni adivinar lo que usted quiso escribir. Para cualquier otro problema que vaya más allá de estas tres correcciones, la herramienta muestra el error de análisis exacto para que pueda corregirlo manualmente.

¿Mis datos JSON están subidos a algún sitio?

No. El análisis, la reparación, el formateo y la conversión se realizan localmente en tu navegador mediante JavaScript. No se envía nada a Logrith ni a ningún otro servidor.

¿La herramienta me indica exactamente dónde está el error?

Sí, cuando el analizador del navegador informa la posición de un carácter, la herramienta la convierte en un número de línea y columna para que puedas localizar el problema rápidamente.

¿Puedo convertir JSON a una interfaz TypeScript?

Sí. Una vez que el JSON se analiza correctamente, la herramienta genera una interfaz básica de TypeScript, infiriendo tipos que incluyen objetos anidados y matrices.

¿Puedo convertir JSON a CSV?

Sí, si el JSON de nivel superior es una matriz de objetos planos. La herramienta crea un encabezado a partir de la unión de todas las claves y escribe una fila por objeto. Si la estructura no se ajusta, explica el motivo en lugar de generar una salida incorrecta.

¿Esta herramienta es de uso gratuito?

Sí, esta herramienta es de uso gratuito, sin necesidad de cuenta, registro ni límite de uso más allá de lo que su navegador pueda soportar.
