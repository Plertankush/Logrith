Pega una lista de URL y elimina las duplicadas exactas, así como las casi duplicadas causadas por barras diagonales finales, mayúsculas y minúsculas, www, parámetros de seguimiento y fragmentos, todo ello en tu navegador.

Opciones de normalización

Trata https://example.com/ y https://example.com como la misma URL.

Trata HTTPS://Example.com y https://example.com como el mismo host. Solo el esquema y el host se normalizan en cuanto a mayúsculas y minúsculas; la ruta y la consulta permanecen exactamente como están escritas, ya que pueden distinguir entre mayúsculas y minúsculas.

Trata www.example.com y example.com como si fueran el mismo host.

Elimina únicamente los parámetros de seguimiento conocidos: utm_source, utm_medium, utm_campaign, utm_term, utm_content, fbclid, gclid, ref, mc_cid, mc_eid. Los demás parámetros de consulta permanecen intactos.

Trata https://example.com/page#section y https://example.com/page como la misma URL.

Desactivado por defecto. Actívalo solo si estás seguro de que las versiones http y https de tus URL ofrecen el mismo contenido, ya que algunos sitios web presentan diferencias reales entre ambas.

    Qué detecta esta herramienta

    • Duplicados exactos: la misma cadena de URL aparece más de una vez.
    • Diferencias en la barra diagonal final: una URL con y sin barra diagonal final después de la ruta.
    • Diferencias en el uso de mayúsculas y minúsculas en los nombres de host: letras mayúsculas o mayúsculas y minúsculas en el esquema o el host.
    • www vs sin www: el mismo servidor con y sin la etiqueta "www." al principio.
    • Parámetros de seguimiento: parámetros de marketing y análisis conocidos que se añaden a una URL idéntica.
    • Fragmentos: un ancla dentro de la página o un hash de enrutador agregado después de un "#".
    • Entradas no analizables: texto que parece ser una URL pero que no se analiza como tal, se marca y se excluye en lugar de intentar adivinarlas automáticamente.

    ¿Qué es la deduplicación de URL?

    La deduplicación de URL consiste en tomar una lista de enlaces y reducirla a una sola entrada por destino único. Suena sencillo, pero la palabra "único" tiene un gran peso en esa frase. Un enfoque directo —comparar las cadenas de URL carácter por carácter— solo detecta duplicados exactos: la misma cadena que aparece dos veces. En la práctica, la mayoría de las URL duplicadas en una lista real no son coincidencias exactas de cadenas. Son casi duplicados: la misma página subyacente, escrita de forma ligeramente diferente. https://example.com/pricing y https://example.com/pricing/ casi siempre apuntan a la misma página, pero como cadenas de texto plano son diferentes. Un proceso de deduplicación ingenuo no detecta esto, y una lista que debería tener 500 URL únicas termina reportándose como 650.

    ¿Por qué se producen las URL casi duplicadas?

    Los elementos casi duplicados no son ruido aleatorio; provienen de un conjunto de fuentes predecibles, y comprenderlas es lo que hace que una herramienta de deduplicación sea realmente útil en lugar de un simple script de búsqueda y reemplazo.

    Parámetros de seguimiento. Las plataformas de marketing añaden parámetros de consulta para rastrear el origen de un clic: utm_source, utm_medium y utm_campaign de las campañas de Google Analytics, fbclid de Facebook, gclid de Google Ads y parámetros similares específicos de cada proveedor en plataformas de correo electrónico y programas de afiliados. El mismo artículo compartido a través de un boletín informativo, un tuit y un anuncio pagado puede generar tres cadenas de URL completamente diferentes que cargan la misma página.

    Inconsistencia en la barra diagonal final. La mayoría de los servidores web tratan /about y /about/ como el mismo recurso, pero el hecho de que un enlace determinado incluya o no la barra diagonal final a menudo depende de la herramienta que lo generó (un CMS, una exportación de mapa del sitio o un enlace escrito manualmente) en lugar de algo significativo sobre el destino.

    Con www frente a sin www. Muchos sitios web ofrecen contenido idéntico independientemente de si la solicitud incluye o no el subdominio "www.", generalmente porque uno redirige al otro. Un rastreador o una herramienta de exportación que no siga las redirecciones antes de registrar una URL capturará ambas formas como si fueran páginas separadas.

    http frente a https. Casi todos los sitios web modernos redirigen las solicitudes http a https, por lo que ambas suelen conducir a la misma página, pero no siempre. Por eso, esta herramienta mantiene esa normalización como opcional en lugar de automática.

    Reglas de distinción entre mayúsculas y minúsculas. Según la RFC 3986, el esquema y el host de una URL no distinguen entre mayúsculas y minúsculas (HTTPS://Example.COM y https://example.com corresponden a la misma autoridad), pero la ruta, la cadena de consulta y el fragmento sí suelen distinguir entre mayúsculas y minúsculas, ya que muchos servidores tratan /Page y /page como recursos distintos. Esta herramienta respeta esta distinción: la normalización de mayúsculas y minúsculas del nombre de host solo afecta al esquema y al host, nunca a la ruta ni a la consulta.

    Fragmentos de URL. La parte que aparece después de un "#" se utilizaba originalmente para enlaces internos de la página, pero ahora también la emplean con frecuencia las aplicaciones de una sola página basadas en JavaScript para el enrutamiento del lado del cliente. En ambos casos, dos URL que solo se diferencian por el fragmento suelen apuntar al mismo recurso del servidor, incluso si el fragmento modifica lo que se ve en pantalla después de que la página se carga.

    Cómo funcionan las opciones de normalización

    Cada opción apunta a una diferencia específica y se combinan: una URL solo se trata como una copia casi idéntica de otra si, después de aplicar todas las opciones habilitadas, las dos formas normalizadas coinciden exactamente. Esta herramienta utiliza la API URL integrada del navegador para analizar cada entrada en lugar de manipular cadenas con expresiones regulares, lo que evita errores sutiles relacionados con el orden de los parámetros de consulta, los caracteres codificados, los puertos predeterminados y otros casos límite que un analizador de cadenas manual suele pasar por alto. La eliminación de parámetros de seguimiento solo elimina una lista fija y conocida de parámetros; no elimina todos los parámetros de consulta, ya que un parámetro no reconocido podría seleccionar una variante de producto, idioma o sección de página diferente, y eliminarlo indiscriminadamente podría hacer que dos páginas realmente diferentes parezcan idénticas.

    Por qué esto importa

    Las listas de URL limpias y sin duplicados son importantes en varias situaciones recurrentes. Las auditorías de backlinks SEO suelen comenzar con una exportación desde una herramienta de backlinks que lista todos los enlaces de referencia, incluyendo muchos que corresponden a la misma página a la que se accede mediante diferentes parámetros de seguimiento o variantes de barra diagonal final. La eliminación de duplicados previa proporciona un recuento preciso de cuántas páginas distintas enlazan realmente a la tuya. La eliminación de duplicados en las listas de enlaces extraídas es rutinaria al crear un rastreador o recopilar enlaces de varias páginas, donde el mismo destino se encuentra con frecuencia más de una vez en formas ligeramente diferentes. La limpieza de una exportación de marcadores elimina las entradas duplicadas que se acumulan a lo largo de los años al guardar la misma página desde diferentes navegadores o debido a conflictos de sincronización. La preparación de una lista de URL para un mapa del sitio o un rastreador se beneficia de la eliminación de duplicados, ya que enviar URL casi duplicadas a un mapa del sitio puede crear la apariencia de contenido duplicado, lo que los motores de búsqueda pueden interpretar como una señal para investigar en lugar de recompensar.

    Cómo utilizar esta herramienta

    Pegue su lista de URL en el cuadro de entrada: la herramienta extrae cualquier elemento con forma de URL del texto pegado, por lo que puede pegar una lista sin formato, un bloque de HTML extraído o notas con enlaces mezclados con otro texto. Elija las opciones de normalización que mejor se adapten a su situación: si está limpiando backlinks para una auditoría SEO, mantenga activadas la eliminación de parámetros de seguimiento y la normalización de barras diagonales finales; si está auditando el comportamiento de redireccionamiento y necesita saber exactamente qué protocolo o variante de mayúsculas y minúsculas se registró, desactive las opciones correspondientes. Haga clic en "Eliminar URL duplicadas" para ver un desglose completo de cuántas URL se encontraron, cuántas se eliminaron como duplicados exactos, cuántas se eliminaron como casi duplicados según las opciones elegidas y cuántas entradas no se pudieron analizar como URL válidas. La lista limpia se puede copiar directamente o descargar como un archivo de texto plano, listo para pegar en una hoja de cálculo, un generador de mapas del sitio u otra herramienta de su flujo de trabajo.

    Preguntas frecuentes sobre el deduplicador de URL

    ¿Qué se considera una URL duplicada?

    Una URL idéntica, byte a byte, es una copia exacta. Una URL casi idéntica es aquella que apunta al mismo recurso, pero difiere en el formato: una barra diagonal al final, mayúsculas y minúsculas en el nombre de host, el prefijo www, un parámetro de seguimiento o un fragmento. Puedes elegir cuáles de estas diferencias tratar como duplicados mediante las opciones de normalización.

    ¿Esta herramienta elimina los parámetros de seguimiento de todas las URL?

    Solo cuando actives esa opción, y únicamente para una lista fija de parámetros de seguimiento conocidos, como utm_source, utm_medium, utm_campaign, fbclid y gclid. Los parámetros de consulta no reconocidos no se modifican, ya que podrían afectar a la página o el contenido que se devuelve.

    ¿Esta herramienta tratará como duplicados las versiones http y https de la misma URL?

    Solo si activas la opción "Tratar http y https como equivalentes", que está desactivada por defecto. Muchos sitios web ofrecen contenido o redirecciones diferentes según se utilicen http o https, por lo que esta herramienta no asume que sean iguales a menos que tú lo indiques.

    ¿Esta herramienta sube mi lista de URL a algún sitio?

    No. La extracción, el análisis, la normalización y la eliminación de duplicados se ejecutan localmente en su navegador mediante JavaScript y el analizador de URL integrado del navegador. No se envía nada a un servidor.

    ¿Qué ocurre con un texto que no es una URL válida?

    La herramienta extrae subcadenas con formato de URL del texto que has pegado mediante una coincidencia de patrones, y luego intenta analizar cada una con la API de URL del navegador. Cualquier elemento que no se pueda analizar como una URL se excluye de la lista depurada y se cuenta por separado para que puedas ver cuántas entradas se omitieron.
