¿Al minimizar el código HTML se eliminan los comentarios?

Sí, comentarios HTML ( ) se eliminan durante la minificación, junto con los espacios en blanco innecesarios entre las etiquetas.

¿La minificación dañará mi HTML?

No, la minificación estándar de HTML solo elimina los espacios en blanco y los comentarios; no altera las etiquetas, los atributos ni el contenido de forma que cambie la representación.

Minimizador y embellecedor de HTML

Esta herramienta comprime el código HTML eliminando comentarios y espacios en blanco innecesarios entre etiquetas para reducir el tamaño del archivo, o bien reformatea el HTML minimizado para convertirlo de nuevo en un código legible y con la indentación adecuada.

¿Por qué minimizar el HTML?

La minimización de HTML elimina comentarios, espacios en blanco adicionales y saltos de línea entre etiquetas que existen únicamente para facilitar la lectura del código fuente, pero que no influyen en la visualización de la página. Los archivos HTML más pequeños se transfieren más rápido por la red, lo que contribuye a una carga inicial más rápida de la página, algo especialmente notable en páginas grandes o para usuarios con conexiones lentas. La mayoría de los procesos de implementación web en entornos de producción minimizan HTML junto con CSS y JavaScript como paso de optimización estándar.
