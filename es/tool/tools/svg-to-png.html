Preguntas frecuentes

¿Por qué convertir SVG a PNG?

PNG es compatible con todas las plataformas, incluidas aquellas y el software antiguo que no son compatibles con SVG, como algunos clientes de correo electrónico o aplicaciones heredadas.

¿El archivo PNG tendrá la misma nitidez que el SVG?

Sí, si se exporta con una resolución suficientemente alta; SVG se basa en vectores y se renderiza correctamente en cualquier tamaño antes de convertirse a píxeles PNG.

¿Puedo obtener un fondo transparente?

Sí, seleccione el modo de fondo "Transparente" para conservar la transparencia en el archivo PNG exportado.

¿Mi archivo SVG se ha subido a un servidor?

No, la conversión se realiza localmente en tu navegador mediante la API de Canvas.

SVG vs. PNG: ¿Cuál es la diferencia?

SVG es un formato de imagen vectorial: describe formas, trazados y texto matemáticamente, lo que significa que se puede escalar a cualquier tamaño sin perder nitidez ni calidad. PNG, por el contrario, es un formato rasterizado (basado en píxeles): almacena una cuadrícula fija de píxeles de color, por lo que escalar un PNG más allá de su resolución nativa provoca desenfoque. SVG es ideal para logotipos, iconos e ilustraciones que necesitan funcionar en varios tamaños, mientras que PNG es el formato más universalmente compatible para situaciones en las que no se dispone de soporte vectorial o no es necesario.

¿Por qué convertir SVG a PNG?

  • Compatibilidad : algunas plataformas, clientes de correo electrónico y software antiguo no renderizan SVG de forma fiable, pero prácticamente todo es compatible con PNG.
  • Redes sociales y miniaturas : muchas plataformas requieren la carga de imágenes rasterizadas en lugar de archivos vectoriales.
  • Generación de favicons e iconos de aplicaciones : normalmente, el formato de entrada requerido para estos flujos de trabajo es el formato PNG rasterizado.
  • Representación uniforme : una imagen PNG se ve exactamente igual en todas partes, mientras que la representación SVG puede variar ligeramente entre navegadores y motores de renderizado.

Elegir la resolución de exportación adecuada

Dado que SVG es independiente de la resolución, puedes exportarlo a PNG en cualquier tamaño sin necesidad de modificar el archivo original; la herramienta simplemente renderiza los datos vectoriales con las dimensiones de píxeles que hayas elegido. Para obtener resultados nítidos en cualquier tamaño (como un icono para pantallas Retina o un elemento de impresión grande), exporta la imagen al doble o más del tamaño en el que la mostrarás, ya que siempre es seguro reducir el tamaño de un PNG de alta resolución, pero aumentar el de uno de baja resolución provoca desenfoque.

Cómo funciona esta herramienta

La herramienta carga tu SVG (ya sea desde un archivo o código pegado) en un elemento de imagen y luego lo dibuja en un lienzo HTML con las dimensiones de salida especificadas. Si eliges un color de fondo, este se rellena antes de dibujar el SVG encima; si eliges "transparente", se omite este paso, conservando la transparencia del SVG original. El lienzo se exporta como un archivo PNG listo para descargar.

Casos de uso comunes

  • Preparación del icono de la aplicación y del favicon: convierta un logotipo vectorial a PNG antes de introducirlo en un generador de favicons o iconos de aplicaciones que requiera una entrada rasterizada.
  • Firmas de correo electrónico y boletines informativos: muchos clientes de correo electrónico eliminan o gestionan incorrectamente los archivos SVG, por lo que convertir primero un logotipo a PNG evita que las imágenes se vean dañadas en Outlook o Gmail.
  • Gráficos para redes sociales: plataformas como Twitter/X, LinkedIn e Instagram requieren la carga de imágenes rasterizadas, por lo que una ilustración SVG debe convertirse a PNG antes de publicarla.
  • Recursos para impresión y presentaciones: algunas herramientas de diseño y versiones antiguas de PowerPoint o Word manejan los archivos PNG de forma más fiable que los archivos SVG incrustados.
  • Generación de marcadores de posición y miniaturas: rasteriza rápidamente un conjunto de iconos en miniaturas PNG para una guía de estilo o una página de vista previa de recursos.

Explicación de los fondos transparentes

Al seleccionar la opción Fondo transparente, la herramienta omite rellenar el lienzo con cualquier color antes de dibujar el SVG, por lo que los píxeles que no estén cubiertos por las formas SVG permanecen completamente transparentes en el canal alfa del PNG exportado. Esto solo funciona correctamente si el propio SVG de origen no tiene un rectángulo de fondo opaco; si su SVG se exportó con una forma de fondo sólida, deberá eliminarla primero del código SVG para lograr una transparencia real.

Manejo de archivos SVG sin dimensiones explícitas

No todos los archivos SVG especifican los atributos de ancho y alto; algunos solo definen viewBox. Si no se encuentra un tamaño explícito, la herramienta recurre a las dimensiones de salida predeterminadas de 512 × 512, que luego puede modificar manualmente. Para obtener mejores resultados con archivos SVG que solo contienen viewBox, ajuste el ancho y el alto de salida para que coincidan con la relación de aspecto del viewBox y así evitar que la imagen se estire o distorsione.

Errores comunes que se deben evitar

  • Exportar con una resolución demasiado baja: dado que el formato PNG no se puede ampliar sin que se produzca desenfoque posteriormente, exporte siempre con una resolución mayor de la que cree necesaria; la reducción de escala posterior no produce pérdidas, mientras que la ampliación no.
  • Olvidar la relación de aspecto: cambiar el ancho y la altura de forma independiente sin que coincidan con las proporciones originales del SVG estirará o comprimirá la imagen.
  • Pegar código SVG incompleto: el código debe incluir las etiquetas de apertura y cierre completas con XML válido; un fragmento parcial copiado desde dentro de un SVG no se renderizará.
