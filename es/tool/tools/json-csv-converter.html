Preguntas frecuentes

¿Cómo convierto JSON a CSV?

Pega una matriz JSON de objetos, elige un delimitador y haz clic en Convertir. Cada objeto se convierte en una fila, y la unión de todas las claves forma la fila de encabezado. Copia el resultado o descárgalo como data.csv y ábrelo en Excel o Google Sheets.

¿Qué ocurre con los objetos anidados?

Con la opción "Aplanar objetos anidados" activada, un valor como {"address": {"city": "Pune"}} se convierte en una columna llamada address.city. Desactive esta opción para mantener los objetos anidados como texto JSON dentro de una sola celda.

¿Cómo se manejan los arrays en CSV?

El formato CSV no admite matrices, por lo que cada matriz se escribe en su celda como texto JSON; por ejemplo, ["admin","beta"]. Esto garantiza la integridad de los datos y permite convertirlos de nuevo posteriormente.

¿Admite comas y comillas dentro de los valores?

Sí. Los valores que contienen el delimitador, las comillas dobles o los saltos de línea se encierran entre comillas, y las comillas internas se duplican, tal como lo exige el estándar CSV (RFC 4180). El analizador CSV también interpreta correctamente estos casos.

¿Por qué los números pierden los ceros iniciales cuando abro el archivo CSV en Excel?

Las hojas de cálculo intentan adivinar el tipo de datos al importarlos y eliminan los ceros iniciales de valores como 00123. Importe el archivo como texto para esa columna o utilice la opción Datos > Desde texto/CSV en lugar de hacer doble clic en el archivo.

¿Qué ocurre si mis objetos JSON tienen claves diferentes?

La fila de encabezado contiene todas las claves encontradas en cualquier objeto. Las filas que no tienen clave obtienen una celda vacía en esa columna.

¿Se suben los datos a un servidor?

No. Ambas conversiones se realizan en tu navegador, por lo que los datos confidenciales permanecen en tu dispositivo.

Acerca del convertidor JSON ⇄ CSV

The Logrith JSON ⇄ CSV Converter changes data between the two formats people use most often to move records around. Paste a JSON array and get a CSV file that opens in Excel, Google Sheets or any database import tool. Paste CSV and get a clean JSON array of objects you can use in code or an API. It handles nested data, quoted fields, different delimiters and ragged records, and it runs entirely in your browser.

JSON y CSV resuelven problemas diferentes. JSON es el formato estándar para API y aplicaciones porque admite anidamiento, matrices y valores tipados. CSV es el formato estándar para tablas porque cualquier hoja de cálculo y herramienta de análisis puede leerlo. Cambiar entre ambos formatos es una tarea diaria para desarrolladores, analistas y profesionales del marketing, por ejemplo, al exportar datos de una API para un informe, importar una hoja de cálculo a una aplicación o preparar un conjunto de datos para un script.

Cómo JSON se convierte en CSV

CSV es plano: filas y columnas, nada más. El convertidor trata cada objeto de tu matriz JSON como una fila. Luego, recopila todas las claves que encuentra en todos los objetos para construir el encabezado, de modo que los registros con campos diferentes se mantienen alineados. Los valores faltantes se convierten en celdas vacías. Si pegas un solo objeto en lugar de una matriz, se convierte en una fila, y una lista de valores simples se convierte en una tabla de una columna llamada value.

Objetos anidados y matrices

Las respuestas reales de las API rara vez son planas. Un usuario podría tener un objeto address y un pedido una lista de artículos. Con la opción de aplanamiento activada, los objetos anidados se convierten en columnas con notación de puntos, como address.city y address.zip, que las hojas de cálculo manejan bien. Los arrays se escriben como texto JSON en una sola celda, como ["admin","beta"], lo que conserva los datos tal cual para que puedas analizarlos posteriormente. Si prefieres mantener los objetos anidados intactos, desactiva el aplanamiento y cada uno se almacenará como texto JSON en su celda.

Cómo CSV se convierte en JSON

El analizador CSV sigue las reglas comunes de la RFC 4180. Comprende campos entre comillas, comillas dobles dentro de un valor entre comillas y saltos de línea dentro de comillas, por lo que una celda como "Smith, Liam" conserva un único valor. Con la opción "La primera fila es el encabezado" activada, la primera línea proporciona los nombres de las claves. Sin ella, las claves se denominan columna1, columna2, etc. La herramienta también puede detectar números, verdadero, falso y nulo, por lo que 42 se convierte en un número en lugar del texto "42". Desactive esta opción si necesita que cada valor permanezca como una cadena, por ejemplo, con códigos postales o identificadores que comienzan con cero.

Elegir un delimitador

La coma es el delimitador predeterminado, pero en muchos idiomas europeos se usa el punto y coma porque la coma es su separador decimal, y los archivos separados por tabulaciones evitan problemas de comillas cuando el texto contiene comas. Elija el delimitador que espera el programa que recibe el archivo. Si un archivo CSV parece tener solo una columna, el delimitador casi siempre es incorrecto.

Problemas comunes y soluciones

  • Error "JSON no válido". La entrada contiene una coma al final, comillas simples o una clave sin comillas. Corríjalo con la herramienta de reparación de JSON y, a continuación, conviértalo.
  • En Excel, todo aparece en una sola columna. El delimitador no coincide con la configuración regional. Pruebe con el punto y coma.
  • Los ceros iniciales desaparecen. Excel cambia 00123 a 123 al abrir un archivo CSV. Importa la columna como texto.
  • Acentos ilegibles. Algunas versiones de hojas de cálculo necesitan una marca de orden de bytes UTF-8 o una configuración de importación UTF-8 explícita para mostrar correctamente los caracteres que no son en inglés.
  • Las columnas aparecen en un orden inesperado. Siguen el orden en que aparecen las claves en los datos. Si es necesario, puedes reordenarlas en tu hoja de cálculo.

Cuándo no usar CSV

Si tus datos están muy anidados, aplanarlos puede generar tablas muy anchas y difíciles de usar, además de que se pierde la estructura. En ese caso, mantén los datos en formato JSON o divide las partes anidadas en tablas separadas. El formato CSV tampoco tiene tipos de datos, por lo que las fechas, los números y los valores booleanos se consideran texto hasta que un programa los interpreta.

Privacidad

Tus datos se procesan mediante JavaScript que se ejecuta en tu navegador. No se suben, almacenan ni registran, lo que hace que la herramienta sea adecuada para listas de clientes, exportaciones internas y otros datos que no deberías pegar en cualquier sitio web.

Paso a paso: Cómo usar el convertidor de JSON a CSV

  1. Elige la dirección

    Seleccione JSON → CSV o CSV → JSON. El cuadro de texto carga un pequeño ejemplo para que pueda ver el formato esperado.

  2. Pega tus datos

    Sustituye el ejemplo por tu propio array JSON o texto CSV. Un único objeto JSON también funciona y se convierte en una fila.

  3. Configurar las opciones

    Seleccione un delimitador, indique si la primera fila es un encabezado y elija si desea aplanar los objetos anidados o detectar los tipos de valor.

  4. Convertir y exportar

    Haz clic en Convertir y, a continuación, copia el resultado o descárgalo como archivo .csv o .json.
