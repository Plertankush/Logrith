What Is a PDF Inspector?

A PDF inspector is a utility that reads the internal structure of a PDF file and reports what's actually inside it, beyond what you see on the page. A PDF is not just an image of text — it's a structured document format containing metadata, font references, embedded objects, and a cross-reference table describing every element. A PDF inspector exposes that structure in a readable report: document properties, the fonts used, how many images are embedded, whether the file is encrypted, and whether it contains forms, bookmarks, or embedded JavaScript.

What This PDF Inspector Checks

This tool opens the PDF using a browser-based PDF parsing engine and reads several categories of information in sequence: the document's basic properties (page count, dimensions, version, size), its metadata fields, the fonts referenced across its pages, an estimate of embedded images, and structural/security details such as encryption status, form fields, bookmarks, and links. Each category is displayed as its own card in the report so you can scan the result quickly.

PDF Metadata

Metadata is descriptive information stored inside the PDF file itself, separate from the visible page content. Common fields include the document title, the author who created it, the creator application used to produce the original content (such as a word processor), the producer application that generated the final PDF (such as a PDF export library), and the creation and modification dates. Not every PDF includes all of these fields — some are stripped by certain export tools, while others are filled in automatically by the software that created the file.

PDF Fonts and Images

Font information matters for publishing and troubleshooting because a PDF can either embed its fonts directly in the file or simply reference font names that must be available on the viewer's system. A PDF with non-embedded fonts can render differently — or substitute a fallback font — on a device that lacks the original font, which is a common cause of unexpected layout shifts when a PDF is opened on a different computer. Checking the font list here helps confirm whether a document is safe to share without font-related rendering issues.

Image count is useful for understanding file size and complexity. A PDF with many high-resolution embedded images is typically far larger than a text-only document, and knowing the approximate image count can help explain why a particular file is unexpectedly large or slow to open.

PDF Security and Structure

This section reports whether a PDF is encrypted or password-protected, whether it contains interactive form fields, whether files are embedded inside it (such as an attached spreadsheet or image), whether it references JavaScript, and whether it includes bookmarks (also called an outline) or clickable links. These structural details matter for document verification — for example, confirming that a contract PDF doesn't contain unexpected embedded files, or checking whether a form-based PDF actually contains fillable fields before sending it out.

Common Reasons to Inspect a PDF

  • Document quality checking: confirming a PDF export retained the correct page count, fonts, and structure before distributing it.
  • Publishing workflows: verifying that a manuscript, report, or e-book PDF has consistent metadata and embedded fonts before submission.
