About the JPG to PDF Tool

The Logrith JPG to PDF tool converts one or more images into a single PDF document, free and entirely in your browser. Upload JPG, PNG, or WEBP files, choose a page size, and each image becomes its own page in the finished PDF — in the order you added them. This is a frequently needed conversion for turning scanned documents, receipts, or photo collections into a single shareable file.

Images and PDFs serve different purposes, and converting between them comes up constantly. A PDF keeps multiple pages together as one file that prints consistently and opens the same way on any device, while individual image files are easier to capture but awkward to send or print as a set. This tool bridges that gap by combining any number of separate image files into one properly formatted PDF document.

Common Reasons to Convert Images to PDF

  • Combining scanned pages. Phone camera scans of a multi-page document, taken as separate photos, can be combined into a single PDF for easy sharing or printing.
  • Submitting documents online. Many application forms and portals require a single PDF upload rather than multiple separate image files.
  • Archiving receipts or records. Converting a batch of photographed receipts into one PDF makes them easier to store, search, and reference later.
  • Creating a simple photo booklet. Combining a sequence of images into a PDF provides a basic, printable booklet format without needing design software.
  • Printing consistency. PDFs print more predictably across different printers and software than a loose folder of image files.

Choosing the Right Page Size

The page size setting determines how each image is placed onto its PDF page. A4 is the standard paper size used across most of the world outside North America, while US Letter is standard in the United States and Canada — pick whichever matches your printer or regional convention if you plan to print the result. The "Fit to Image" option skips standard paper dimensions entirely and instead creates a page sized exactly to match each image's own dimensions, which avoids any white space or scaling and is the best choice when the PDF is only going to be viewed digitally rather than printed on standard paper.

How the Conversion Works

When you convert your images, the tool reads each image file, creates a new page in a PDF document for it using a PDF generation library, and embeds the image data onto that page at either its original size or scaled to fit the chosen page dimensions. Because this all happens through code running in your browser rather than a server, there's no waiting for an upload and download round-trip — the finished PDF is ready to download as soon as processing completes.

JPG to PDF vs. PDF to JPG

It's worth knowing the difference between this tool and its counterpart. JPG to PDF, covered here, takes one or more standalone images and bundles them into a single PDF document — useful when you have loose images that need to become one shareable file. PDF to JPG does the reverse, extracting each page of an existing PDF as a separate image file — useful when you need to use a specific page as a standalone image, for example in a presentation or on a website. Logrith's PDF to JPG tool handles that opposite direction.

Tips for Best Results When Scanning with a Phone

If you're photographing physical pages to convert into a PDF, a few small habits make a noticeable difference in the final result. Shoot in good, even lighting to avoid shadows falling across the text, and keep the phone as parallel to the page as possible to avoid a skewed or trapezoid-shaped capture. Try to keep a consistent distance and angle across all pages so that when they're combined into one PDF, the pages look reasonably uniform rather than wildly different sizes. If a page comes out tilted, consider cropping or rotating it with Logrith's other image tools before converting, since this tool places each image as-is onto its PDF page without any automatic straightening.
