Frequently Asked Questions

Is it safe to check my password here?
Yes, completely safe. All analysis is done using JavaScript running entirely in your browser. Your password is never sent to any server, never stored, and disappears when you close the tab.
What is password entropy?
Entropy measures how unpredictable a password is, in bits. Higher entropy = more secure. Entropy = log2(charset_size^length). A password with 60+ bits of entropy is considered strong against brute-force attacks.
What makes a password strong?
A strong password: is 12+ characters long (16+ is better), uses uppercase and lowercase letters, digits, and special symbols, is not a dictionary word or common pattern, is unique to each account, and is not based on personal information.
What is a crack time estimate?
Crack time estimates how long a computer would take to guess your password using brute-force. "Online attack" assumes a rate-limited web login (1000/s). "Offline fast hash" assumes a GPU cracking MD5 hashes (~10 billion/s).
Why does adding a few extra characters matter so much?
Each additional character multiplies the total number of possible combinations, so password strength grows exponentially with length, not linearly — a 16-character password isn't twice as strong as an 8-character one, it's astronomically stronger.
Does this tool check my password against known leaked password lists?
This tool analyzes your password's structure, length, and character variety locally. It flags common patterns and dictionary-like structures but does not check against external breach databases, since doing so securely would require sending your password elsewhere.
Should I use a password manager instead of memorizing strong passwords?
Yes, for most people a password manager that generates and stores long, random, unique passwords for every account is more practical and more secure than trying to memorize many strong passwords.

Password strength isn't just about following a vague rule like "use a mix of letters and numbers." The actual security of a password comes down to how many possible combinations an attacker would need to try before guessing it correctly, and that number is shaped by both length and character variety — with length mattering considerably more than most people realize.

What This Tool Measures

  • Length. The single biggest factor in password strength — each additional character multiplies the total possible combinations.
  • Character variety. Whether the password uses uppercase letters, lowercase letters, digits, and special symbols, each of which expands the pool of possible characters at each position.
  • Entropy. A measurement, in bits, of how unpredictable the password is overall, calculated from its length and character set size.
  • Common patterns. Whether the password resembles a dictionary word, a keyboard pattern (like "qwerty"), or a predictable substitution (like "P@ssw0rd"), all of which make a password far easier to guess than its raw length suggests.

Understanding Password Entropy

Entropy is calculated using the formula log2(character set size ^ password length), and it represents, in bits, how many guesses an attacker would theoretically need to try in the worst case. A password using only lowercase letters has a character set of 26, while one mixing uppercase, lowercase, digits, and symbols might have a character set closer to 90-95. Because entropy grows with the length exponent, a longer password with a smaller character set can still be stronger than a shorter password with a larger character set — which is part of why security experts increasingly recommend long passphrases over short, complex-looking passwords.

Why Length Matters More Than Complexity

A common misconception is that adding symbols and numbers to a short password makes it strong. In reality, length has a much larger effect on total possible combinations than character variety does. An 8-character password, even with a full mix of character types, has fewer possible combinations than a 16-character password made of just lowercase letters. This is why many current security guidelines favor long, memorable passphrases — like a random string of several unrelated words — over short, symbol-heavy passwords that are both harder to remember and, counterintuitively, often weaker.

How Crack Time Estimates Work

This tool estimates how long different types of attacks would realistically take to guess your password. An "online attack" scenario assumes an attacker is guessing through a live login form, which is typically rate-limited to around 1,000 attempts per second by the target service's security measures. An "offline fast hash" scenario assumes an attacker has somehow obtained a database of hashed passwords and is cracking them offline using powerful GPU hardware, capable of roughly 10 billion guesses per second for weaker hash algorithms like unsalted MD5. The difference between these two numbers is enormous, which is exactly why a password that feels "secure enough" against a login form could still be dangerously weak if the underlying password database were ever breached.

Practical Tips for Stronger Passwords

1. Prioritize lengthAim for at least 12-16 characters, longer where the service allows it.
2. Avoid predictable patternsSkip keyboard sequences, repeated characters, and simple substitutions like "@" for "a".
3. Make every password uniqueReusing a password across accounts means one breach can compromise all of them.
4. Consider a password managerGenerating and storing long, random, unique passwords for every account removes the need to memorize them all.
