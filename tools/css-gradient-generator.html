Linear vs. Radial Gradients

A linear gradient transitions between colors along a straight line at a specified angle — 0° points upward (bottom to top), 90° points rightward (left to right), and so on. A radial gradient instead transitions colors outward from a central point in expanding circles or ellipses, useful for spotlight effects, glowing buttons, or circular color transitions.

How Color Stops Work

Each color stop defines a color and a position (as a percentage) along the gradient. With two stops, you get a simple two-color transition. Adding more stops lets you create more complex, multi-color gradients — for example, a sunset effect moving from orange to pink to purple, or a rainbow-style gradient with many distinct color bands.

How the Gradient Angle Changes the Result

For linear gradients, the angle value determines where the gradient starts and ends. An angle of 0deg runs from bottom to top, 90deg runs from left to right, 180deg runs from top to bottom, and 270deg runs from right to left. Values in between produce diagonal transitions — 45deg, for instance, moves from the bottom-left corner toward the top-right. Because the angle wraps around a full circle, 0deg and 360deg produce the same visual result.

Radial Gradient Behavior

The radial gradient output here uses the circle keyword, which means the gradient spreads evenly in all directions from the center of the element regardless of its width or height. This is a common choice for spotlight effects, glowing icons, or badge backgrounds where you want a perfectly round color transition rather than one stretched to match the element's aspect ratio.

Choosing Colors for a Smooth Transition

Gradients tend to look most natural when adjacent color stops share some hue or brightness relationship — for example, moving through shades of the same color family, or between colors that are near each other on the color wheel. Jumping between unrelated hues (like bright green directly to deep red) can create a muddy band in the middle of the transition, which is easier to spot and fix when you can see the live preview update in real time.

Multi-Stop Gradients for Complex Effects

Two color stops produce a simple fade, but adding three, four, or more stops opens up effects like sunset skies, aurora backgrounds, or brand-colored banners that cycle through a full palette. Each added stop gets its own position percentage, so you can bunch several colors close together for a sharp transition in one area while leaving a slow fade elsewhere in the same gradient.

Common Mistakes When Building Gradients

  • Overlapping stop positions — setting two stops to the same percentage creates a hard color break instead of a smooth blend, which is sometimes intentional but often accidental.
  • Too many stops — piling on five or six colors can make a gradient look noisy rather than polished; two or three well-chosen stops usually reads cleaner.
  • Ignoring contrast — if you plan to place text over the gradient, check that the darkest and lightest parts still leave the text readable.
