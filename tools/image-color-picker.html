How This Tool Works

Your uploaded image is drawn onto an HTML canvas, which gives direct pixel-level access to color data. When you click anywhere on the image, the tool reads the exact red, green, and blue values at that pixel coordinate and converts them to both RGB and HEX notation instantly. For the dominant palette, the tool samples pixels across the entire image, groups similar colors together, and surfaces the most frequently occurring colors as a clickable swatch grid.

Privacy and Local Processing

All color analysis happens locally in your browser using the Canvas API's pixel data access — your image is never uploaded to any server, keeping unpublished photos and designs completely private.

How the Dominant Palette Is Extracted

To find the most common colors across a potentially large image without scanning every single pixel, the tool samples pixels at a calculated interval based on the image's total pixel count, keeping the analysis fast even on large photos. Each sampled pixel's red, green, and blue values are rounded down to the nearest multiple of 32, which groups visually similar shades (like slightly different greens in foliage) into the same bucket rather than treating every minor variation as a separate color. The ten buckets with the highest pixel counts become the final palette, ordered from most to least common.

Why Colors Are Rounded Into Buckets

A typical photo can contain tens of thousands of distinct exact RGB values even in a small area, because of lighting gradients, compression artifacts, and natural color variation. Without rounding, a true "most common color" count would be almost meaningless — nearly every pixel would be unique. Rounding to steps of 32 per channel groups nearby shades together so the resulting palette reflects the image's real visual color regions (sky, skin, foliage, background) rather than noise.

Canvas-Based Pixel Reading Explained

The tool draws your uploaded image onto an HTML5 canvas element, which exposes a getImageData() method giving direct access to the raw RGBA value of any pixel coordinate. When you click the image, the click position is translated from screen coordinates to canvas pixel coordinates (accounting for any scaling if the image was resized to fit the display area), and that exact pixel's color is read and displayed. This is the same low-level approach browser-based image editing tools use internally for color sampling.

Image Size and Display Scaling

Large images are automatically scaled down to fit within a maximum display width so the canvas stays usable on screen, but the color sampling still reads the correct pixel because click coordinates are converted back through the scale ratio before looking up the color. This means the HEX and RGB values you get are accurate to the image as displayed, regardless of how large the original upload was.

Difference From a Desktop Eyedropper Tool

A system-level eyedropper (like the one built into some operating systems or design apps) can sample any pixel on your entire screen, while this tool only samples pixels within the uploaded image itself. That's usually an advantage for web work, since it means you can share just the image file with the tool rather than needing the full design app open, and the sampling works identically across any device with a browser.
