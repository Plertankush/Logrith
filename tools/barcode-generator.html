What Is CODE128?

CODE128 is one of the most widely used linear barcode formats, capable of encoding the full ASCII character set (letters, numbers, and symbols) at high density. It's commonly found on shipping labels, product packaging, and inventory tags because of its compactness and reliability. Unlike simpler formats like Code39, CODE128 includes a mandatory checksum digit calculated from the encoded data, which helps scanners detect and reject misread barcodes.

How This Tool Generates a Valid Barcode

Each character you enter is mapped to a numeric value according to the CODE128 Subset B standard, and a checksum is calculated by summing each value multiplied by its position, then taking the result modulo 103 — exactly as the CODE128 specification requires. This checksum value is appended to the encoded sequence, along with mandatory start and stop patterns, ensuring the resulting barcode is standard-compliant and readable by any real barcode scanner, not just a visual approximation.

Understanding CODE128 Subset B

CODE128 actually has three subsets (A, B, and C) optimized for different kinds of data — Subset C packs pairs of digits for very dense numeric encoding, while Subset A and B cover the full printable ASCII range with different control-character support. This tool uses Subset B, which covers all standard uppercase and lowercase letters, digits, and common punctuation (ASCII values 32 through 126), making it the right choice for general-purpose alphanumeric codes like product SKUs, names, and mixed-format reference numbers rather than purely long numeric strings.

How the Checksum Prevents Misreads

Every valid CODE128 barcode includes a checksum character calculated from the data it encodes, which this tool computes by taking the start code's value, adding each subsequent character's value multiplied by its position in the sequence, and reducing the total modulo 103. A scanner recalculates this same checksum from what it reads and compares it to the checksum encoded in the barcode — if they don't match, the scanner rejects the read instead of reporting incorrect data, which is why a correctly calculated checksum (as this tool produces) matters for real-world reliability, not just visual appearance.

Why This Produces a Scannable Barcode, Not Just an Image

A barcode isn't just black and white stripes arranged to look right — each character maps to one of 107 precise 11-bit bar-and-space patterns defined by the CODE128 specification, and the sequence must begin with a valid start pattern and end with the standard stop pattern for a scanner to recognize it at all. This tool looks up each encoded value in the official CODE128 pattern table and renders bars pixel-for-pixel according to that pattern, rather than generating a barcode-like image that only resembles a real one — meaning the output can be scanned by real hardware and scanning apps, not just displayed for visual reference.

Choosing Bar Width and Height

Bar width controls how many pixels wide each unit bar is — thinner bars make a more compact barcode but require a higher-resolution scanner or printer to read reliably, while thicker bars are more forgiving for lower-quality printing or phone camera scanning but produce a wider image. Height is mostly a readability and aesthetic choice, since CODE128 is a 1D (linear) format read horizontally, though taller bars do make it easier for a handheld scanner to get a clean read if the scan angle isn't perfectly level.

CODE128 vs. Other Barcode Formats

CODE128 is denser than older formats like Code39, meaning it can encode the same data in a shorter physical length, which matters when label space is limited. It differs from UPC/EAN formats used on retail packaging, which are fixed-length numeric codes tied to a product registration system (GS1) rather than arbitrary text — CODE128 is the better fit for internal reference codes, tracking numbers, and asset tags where you control both the encoding and the scanning, rather than for retail point-of-sale barcodes that need to match a registered product number.

Printing Tips for Reliable Scans

For a barcode to scan reliably when printed, it needs a clear quiet zone (blank space) on either side — this tool automatically adds that margin around the generated bars. When printing, avoid scaling the image in a way that blurs the bar edges, and test a printed label with an actual scanner or a phone scanning app before producing a full batch, since printer resolution and paper quality can affect how cleanly thin bars reproduce.
