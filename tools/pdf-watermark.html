Add a Text Watermark to Your PDF

Why Watermark a PDF?

  • Mark draft documents clearly as "DRAFT" or "NOT FINAL" before sharing for review.
  • Protect confidential content by stamping "CONFIDENTIAL" across sensitive reports or contracts.
  • Brand shared documents with a company name or website across every page.
  • Discourage unauthorized redistribution of documents like ebooks, reports, or course materials.

Choosing Good Watermark Settings

A diagonal watermark (around 45°) at moderate opacity (20–40%) is the classic, professional-looking style — visible enough to serve its purpose without making the underlying document hard to read. Higher opacity and a horizontal orientation make the watermark more prominent and harder to ignore, useful when the watermark itself is the primary message (like a large "SAMPLE" stamp on a preview document).

How This Tool Works

Using the pdf-lib library, this tool loads your PDF, and for every page, draws the watermark text at the specified size, color, opacity, and rotation, centered on the page. The result is a new PDF file with the watermark permanently embedded as part of the page content — not just a visual overlay — so it stays in place regardless of what PDF viewer is used to open the file afterward.

Privacy and Local Processing

All watermarking happens locally in your browser using pdf-lib — your PDF is never uploaded to a server, keeping confidential documents completely private during processing.

Text Watermark vs. Image Watermark

A text watermark is lighter-weight and keeps the file size small, since it's drawn using an embedded font rather than an embedded image. It's also easy to adjust — change the wording, color, or angle and reapply in seconds. An image-based watermark, such as a logo, is better suited for branding where a wordmark or graphic needs to appear consistently; this tool focuses on text, which covers the most common use cases like "DRAFT," "CONFIDENTIAL," or a company name.

Where the Watermark Is Positioned

The watermark text is centered on each page both horizontally and vertically, with its width calculated from the selected font and size so it sits exactly in the middle regardless of how long the text is. Because the tool uses a bold Helvetica font embedded directly into the PDF, the watermark renders identically across every PDF viewer and operating system, rather than depending on a font that might not be installed on the reader's device.

Common Use Cases

  • Legal and business documents: stamping contracts, proposals, or invoices as "DRAFT" before a final version is approved.
  • Academic and research papers: marking a working paper as "PREPRINT" or "NOT FOR CITATION" before peer review.
  • Digital products and ebooks: adding a buyer's name or order ID as a lightweight deterrent against unauthorized sharing.
  • Internal reports: labeling sensitive financial or HR documents as "INTERNAL USE ONLY" before distribution.

One File at a Time, Every Page Covered

The tool processes one PDF per run and loops through every page in that document, applying the same watermark text, size, color, opacity, and rotation to each one. There's no option to watermark only specific pages or to vary the text per page — if you need a uniform stamp across an entire document, this covers it in a single click; for page-specific watermarks, you'd need to split the PDF first.

Why the Watermark Can't Be Removed by the Recipient

Because pdf-lib draws the watermark text as actual content on each page — not as a separate layer or metadata field — it becomes part of the page just like the original text and images. A recipient opening the file in a standard PDF viewer has no built-in way to toggle it off, which is why keeping your original, unwatermarked file is important if you'll need a clean copy later.

Doing This Manually vs. Using This Tool

Without a dedicated tool, adding a watermark to every page of a PDF typically means using desktop software like Adobe Acrobat, which often requires a paid subscription, or manually editing each page in a design tool and re-exporting — both slow for a document with many pages. This tool applies the same watermark to every page of the file in one pass, in the browser, with no installation or account required.

Choosing a Watermark Color

Red is a common default for "CONFIDENTIAL" or "DRAFT" stamps because it stands out as a warning against a plain white page background. Gray or a muted tone works better when the watermark is meant to be present but unobtrusive, such as a faint company name on every page of a public-facing document. The color picker lets you pick any hex value, so you can match a brand color if the watermark is meant to double as light branding rather than a warning label.

Font Size and Readability

A large font size relative to the page, combined with high opacity, makes the watermark the dominant visual element — useful for a "SAMPLE" stamp meant to prevent a preview document from being used as a final copy. A smaller size with low opacity keeps the watermark present for identification purposes without interfering with reading the underlying text, which is the better choice for internal documents that still need to be fully legible.

What Happens to Encrypted or Corrupted PDFs

If the uploaded file is password-protected, encrypted, or corrupted in a way that pdf-lib cannot parse, the watermarking step will fail and the tool shows an error message rather than producing a broken file. Removing the password protection first, or confirming the PDF opens correctly in a standard viewer, resolves this in most cases.
