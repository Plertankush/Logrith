About Logrith Global Tools

This category groups together utilities designed for a worldwide audience rather than any single region — practical browser-based tools for working with documents, data, and content that developers, writers, and everyday users need regardless of where they're located.

The PDF Inspector and Image Privacy Cleaner both focus on understanding and cleaning files before you share them — checking what's inside a PDF, or stripping hidden location and device metadata from a photo. The JSON Repair Tool and CSV Cleaner help developers and data-focused users fix and validate structured data formats that power APIs, configuration files, and spreadsheets.

The AI Token & Context Calculator and Markdown to HTML Converter support common AI and content workflows — estimating prompt size before sending it to a language model, or converting written content into clean HTML for publishing. The URL Deduplicator rounds out the set with a practical utility for anyone managing large lists of links for SEO, research, or data cleanup.

Every tool in this category processes your input locally in the browser wherever technically possible, requires no account, and has no paid API dependency.

Who Uses These Tools

Developers reach for the JSON Repair Tool when an API response or config file won't parse and the error message doesn't point at the exact problem — pasting it in highlights the broken syntax and offers a one-click fix. Data analysts and spreadsheet users run exports through the CSV Cleaner before importing them into another system, since duplicate rows and stray whitespace are a common cause of failed imports.

Anyone sharing photos publicly — on a marketplace listing, a forum, or social media — uses the Image Privacy Cleaner first, since most phone cameras embed GPS coordinates and device details in a photo's EXIF data by default. Writers and documentation teams use the Markdown to HTML Converter to move content between a Markdown-based editor and a CMS that expects HTML, and SEO practitioners use the URL Deduplicator to clean up crawl exports and backlink lists before analysis.

With AI tools charging by the token, people drafting long prompts or feeding documents into a model's context window use the AI Token & Context Calculator to estimate cost and check they're within a model's limit before submitting.

Frequently Asked Questions

Are these tools free to use?

Yes. All seven Global Tools are completely free, with no account, signup, or usage limit beyond what your browser and device can handle.

Do these tools upload my files to a server?

Wherever technically possible, processing happens entirely in your browser. Each tool's page clearly states its local-processing behavior.

Do I need to create an account to use these tools?

No. Every tool in this category is designed for instant use without registration or login.

Are these tools suitable for international use?

Yes. This category is specifically designed for a global, English-speaking audience rather than any single country or region.

Why does the Image Privacy Cleaner matter — what's actually in a photo's metadata?

Most smartphone cameras automatically embed EXIF data in every photo, which can include exact GPS coordinates, the device model, and the date and time the photo was taken. The Image Privacy Cleaner strips this before you post the photo publicly, without re-compressing or altering the visible image.

Can the JSON Repair Tool fix any broken JSON?

It automatically fixes common issues like trailing commas, missing quotes, and single quotes instead of double quotes. Severely malformed JSON may still need manual correction, but the tool's error highlighting shows you exactly where to look.
