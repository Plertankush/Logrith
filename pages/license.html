Why this page exists

Logrith's tools are written almost entirely in vanilla JavaScript, with no heavy framework underneath. For a handful of genuinely hard problems — reading and writing PDF files, rendering PDF pages to images, generating scannable QR codes — we rely on a small number of focused, well-maintained open source libraries instead of reinventing that work from scratch. This page exists to be transparent about exactly which libraries are used, what they do, and under what license, so anyone auditing the platform's dependencies can verify it directly.

Every library listed above is used under its original open source license, unmodified. We don't fork, relicense, or claim authorship of any third-party code — the credit and license links above point to the original source so you can confirm the terms yourself.

Licensing questions

Can I use Logrith's output commercially?

Yes. Anything you create using a Logrith tool — a compressed image, a merged PDF, a generated QR code — is yours to use however you like, including commercially. The open source licenses on this page cover the libraries that power the tools, not the files you produce with them.

Can I reuse Logrith's design or source code?

The Logrith name, logo, interface design, and original source code are proprietary, as noted above. The open source libraries we depend on can of course be used by anyone under their own licenses — just not by copying them out of Logrith's codebase specifically.

What if a dependency's license changes or a library is updated?

This page is updated whenever the set of libraries Logrith depends on changes. If you ever spot something here that looks out of date, the Contact page is the fastest way to flag it.
