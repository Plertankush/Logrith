Troubleshooting Before You Report

A tool isn't loading or the page looks broken

Try a hard refresh first (Ctrl+Shift+R on Windows, Cmd+Shift+R on Mac) — this clears a stale cached version of the page, which is the most common cause of a tool appearing broken. If that doesn't help, try the same tool in a different browser to narrow down whether the issue is browser-specific.

A file upload or download isn't working

Most Logrith tools process files entirely in your browser, so a failed upload is usually a browser permission issue (check that file access isn't blocked) or a very large file exceeding what your device's memory can handle. If a specific file type consistently fails, that's useful detail to include in your report.

A calculation or conversion result looks wrong

Double-check the input units or format first — a surprising number is often a mismatched unit rather than a bug. If you're confident the result is incorrect, include your exact input and the result you got in your report so we can reproduce it precisely.

How fast do you fix reported bugs?

Most confirmed bugs are fixed within 48 hours of being reported. A clear, reproducible report — the tool name, the exact steps, and what you expected versus what happened — is what makes that turnaround possible.

What if my issue isn't a bug, just a missing feature?

That's still worth reporting here, or through the suggestion option on the Contact page. Feature requests get reviewed alongside bug reports, and the most commonly requested ones tend to get prioritized first.
