# Logrith

### Practical Web Tools. One Place.

**Logrith** is a browser-first utility platform that brings practical tools for calculations, conversions, text processing, development, images, PDFs, productivity, and selected AI-assisted workflows into one place.

## Overview

Logrith is built around a simple product idea:

> **Make useful digital utilities easy to discover and quick to use.**

Instead of using a different website for every small task, Logrith provides a centralized collection of focused browser tools.

The platform is designed for students, developers, creators, professionals, and everyday internet users who need practical digital utilities.

# Architecture

## Static-First Architecture

The current production website is primarily structured as a static web project.

This provides several advantages:

- Simple deployment
- Low infrastructure overhead
- Fast page delivery
- Easy hosting
- Simple development workflow
- Strong browser compatibility
- Straightforward maintenance

Individual tools can remain relatively independent while shared components maintain consistency across the platform.

---

# Browser-First Processing

A major design preference of Logrith is:

> **If a task can reliably be completed in the browser, browser-side processing is preferred.**

This is particularly useful for:

- Images
- PDFs
- Text
- Calculations
- Encoding
- Decoding
- Formatting
- Conversions

Browser-side processing can reduce unnecessary network dependency and, for suitable tools, reduce the need to send user data to a remote server.

However, not every Logrith feature necessarily operates entirely locally.

Processing behavior depends on the implementation of each individual tool.

---

# Privacy Approach

Privacy is an important consideration in Logrith's development.

Where practical, user-provided data should be processed locally in the browser.

This is particularly relevant for file-based utilities.

The project also aims to avoid unnecessary account requirements for basic utilities.

However, Logrith avoids making privacy claims that are broader than the actual implementation.

If a feature depends on a remote service, network request, analytics system, or other external dependency, that behavior should be evaluated separately.

### Privacy Principle

```text
Local Processing
       ↓
When Technically Practical
       ↓
Less Unnecessary Data Transfer
```

A typical feature goes through the following process:

### 1. Problem

Identify a useful task or user need.

### 2. Product Definition

Define what the tool should accomplish.

### 3. Requirements

Define:

- Inputs
- Outputs
- User interactions
- Edge cases
- UI requirements
- Technical constraints

### 4. Implementation

AI-assisted coding is used to accelerate implementation.

### 5. Review

The implementation is inspected for:

- Correctness
- UI quality
- Responsiveness
- Consistency
- Accessibility
- Maintainability

### 6. Testing

The feature is tested against realistic and invalid inputs.

### 7. Iteration

Issues are fixed and the implementation is refined.

### 8. Deployment

The updated feature is published.

### 9. Observation

Real usage can inform future improvements.

# Running Locally

Clone the repository:

```bash
git clone https://github.com/Plertankush/Logrith.git
cd Logrith
```

Serve the project using a local HTTP server.

For example, with Python:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

Running through HTTP is recommended instead of opening `index.html` directly because the project uses relative resources and browser behavior that is more reliable through a local server.

# Bug Reports

```text
Tool:
Image Compressor

Problem:
The generated output does not match the expected compression result.

Steps:
1. Open the tool
2. Upload an image
3. Select compression settings
4. Download the result

Expected:
The output should follow the selected settings.

Actual:
The result differs from the expected behavior.

Environment:
Browser:
Device:
Operating System:
```

Clear reproduction details make investigation easier.
